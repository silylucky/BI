# 走查剧本（功能全量 · 降级用）

> **优先**：由 [scenario-playbook](../../scenario-playbook/SKILL.md) 生成的 `.dev/playbooks/*/critical.md`（业务关键路径）。  
> **本文**：无业务剧本时的**通用幕降级**；或作为剧本未覆盖菜单的烟测补全。使用降级时报告必须写明「无业务剧本 / 部分 generic」。

按幕勾选；可按产品删减，但**须在报告写明跳过原因**。每步稳定后截图。

## 幕 0 · 预检

| ID | 步骤 | 通过判据 |
|----|------|----------|
| W0.1 | 打开 `base_url` | 非连接拒绝；有文档标题或根节点 |
| W0.2 | 未登录访问受保护路由（若有） | 重定向登录或诚实无权限，非白屏 |
| W0.3 | 打开登录页 | 表单可见；Console 无 error |

## 幕 1 · 登录

| ID | 步骤 | 通过判据 |
|----|------|----------|
| W1.1 | 错误密码一次（可选） | 有错误提示；不白屏 |
| W1.2 | 正确 `.dev` 账号登录 | 达 `success` 判据；壳可见 |
| W1.3 | 登录后 Console/网络 | 无 error；无意外 5xx |

## 幕 2 · 壳与导航

| ID | 步骤 | 通过判据 |
|----|------|----------|
| W2.1 | 侧栏/顶栏完整 | 非空壳；品牌/用户区可见 |
| W2.2 | 逐项点击**全部**一级菜单 | 无 404/空白；URL 与菜单一致 |
| W2.3 | 二级菜单（若有） | 同上 |
| W2.4 | 浏览器后退/刷新深链 | 状态可恢复或诚实登录墙 |

## 幕 3 · 分域功能（按路由表展开）

对每个业务域/路由组复制下行（Agent 生成勾选表时展开为具体页）：

| ID | 步骤 | 通过判据 |
|----|------|----------|
| W3.x.1 | 进入列表/主视图 | 数据或诚实空态；无永久 Skeleton 冒充 |
| W3.x.2 | 打开筛选/搜索（若有） | 有反馈；结果区域更新 |
| W3.x.3 | 打开创建/编辑承载（若 `allow_writes`） | Dialog/Sheet/页；校验可见 |
| W3.x.4 | 提交合法数据（若允许写） | loading → 成功反馈；列表更新 |
| W3.x.5 | 提交非法数据（若允许写） | 字段错误，不静默 |
| W3.x.6 | 危险操作（删） | 只打开确认框；`allow_destructive` 才确认 |
| W3.x.7 | 详情/深链 | 可打开；硬刷新不丢关键上下文（或可说明） |

**只读模式**（`allow_writes: false`）：W3.x.3 仅「打开承载再关闭」；跳过真正提交，勾选表标「只读跳过」。

## 幕 6 · 收尾

| ID | 步骤 | 通过判据 |
|----|------|----------|
| W6.1 | 登出（若有） | 回登录或公网页；再访受保护路由被拦 |
| W6.2 | 汇总 Console | 全程 error 列表为空（白名单外） |

## 与路由清单合并算法

1. 若可得前端路由表/菜单源 → 列出全部已挂业务路由。  
2. 每条路由至少映射 **W3.x.1**（进入+截图+Console）。  
3. 标杆页（ui-ux-reviewer 或用户点名）额外做视觉加深 + baseline diff。  
4. 认证回调、纯 redirect、Storybook → 排除并注明。

## 失败时

- 立刻截图 + 导出当时 console 末 50 行 + 失败请求 URL/status  
- 勾选表该行 `fail`；**后续同域可继续**，除非是 W1 登录失败（登录失败则中止功能幕）  
- 不自动「换个账号再试」除非 `.dev` 提供备用角色
