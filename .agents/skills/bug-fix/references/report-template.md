# Bug 分析 / 决策卡模板

按序填空；简短优先。给用户看时用中文。

```markdown
# Bug 决策卡

## 现象
- 期望：
- 实际：
- 复现：（步骤 / 环境 / 必现性）
- 证据：（日志 / 堆栈 / 请求 / 截图 / 用例）

## 根因
- 一句话根因：
- **主层**：语法/机械 | 代码/实现 | 流程/产品规则 | 架构/缝
- 次层（可选）：
- 分层依据：（一句）
- **最合理修法**：A 点修 | B 收拢 helper | C 缝上统一 | D 先改规则 | E 缓解+回流 | F Won't fix
- 为何不是更弱点修：（一句；对照扫描结果）

## 扫描摘要（code-scanning）
- 已用：rg / ast-grep / codegraph（勾选实际用到的）
- 关键符号 / 模式 P：
- Blind spot：（未装工具 / 索引过期 / 动态分发未复核 等；无则写「无」）

## 点线面
| 粒度 | 结论 | 证据 |
|------|------|------|
| 点 | | |
| 线 | 清 / 债 N 处 | |
| 面 | 候选 ~N；可批量？是/否 | |

## 同类发散（换皮防漏）
| 轴 | 仍会炸？ | 候选（路径/符号） | 确信 |
|----|----------|-------------------|------|
| 参数/数据 | 是/否/未测 | | 同源/疑似/排除 |
| 函数/符号 | | | |
| 页面/路由/入口 | | | |
| 动词/对称 | | | |
| 端/角色/租户 | | | |
| 环境/客户端 | | | |

- 发散候选合计：~N（去重后）
- 可与面合并批量？是/否（手法是否同一模板）

## 伤情（多维摘要）
- 严重度：阻断 / 高 / 中 / 低
- 数据/安全：
- 爆炸半径：
- 新旧/触发型：

## 我的推荐（必填，不得留白让用户自己选）

> **推荐：选项 N — <一句话说清做什么>**

- 策略：与上方「最合理修法」一致（缓解 | 点修 | 线修 | 面修 | 回流 | Won't fix）
- 落地方式：本会话点修 | **go-fast 批量** | 缓解后回流

### 为什么推荐它（逐维给结论 + 证据，不适用就写「不适用」并说明）

| 维度 | 该选项的表现 | 依据（扫描命中 / 影响面 / 伤情） |
|------|--------------|----------------------------------|
| **架构与边界** | 修在缝上还是在调用方特判？会不会固化假缝 | |
| **长期维护** | 下次换参数/入口是否还要再开同类单；债是收敛还是繁殖 | |
| **可靠性与正确性** | 是否打在因果链上；失败是否可见；有无竞态/幂等/超时残留 | |
| **爆炸半径与回滚** | 触及文件与调用方规模；回滚粒度；能否分步验证 | |
| **成本与时效** | 工作量对比伤情紧迫度；是否需要迁移/ADR 拖长战线 | |
| **验证可行性** | 能否写出会红的测试；发散候选可否抽检 | |

### 为什么不推荐其他选项（每个被否的都要一句，不能只夸推荐项）

| 选项 | 不推荐的原因 | 什么情况下它反而更好 |
|------|--------------|----------------------|
| 1 只修点 | | |
| 2 点+线 | | |
| 3 点+线+面 | | |
| 4 缓解+回流 | | |

### 推荐的代价（诚实写，不许只列好处）
- 风险与回滚：
- 不修/缓修的债：
- 推荐结论的置信度：高 / 中 / 低 —— 若「中/低」，写清哪条证据缺失（Blind spot、未验证的发散轴、规则未确认）

## 验证与防复发
- 验证计划：（原复现 + 发散抽检 …）
- 防复发：（测试 / 门禁 / 观测 / 文档）

## 请确认（是否修复？）
> 请选一项回复；**「← 推荐」标在上一节选定的那项上**，不要固定标在某个编号：

- [ ] 1 只修点（本会话；线/面/发散记债）
- [ ] 2 修点+线（**go-fast**）
- [ ] 3 修点+线+面含发散（**go-fast 批量**）
- [ ] 4 缓解 + 回流计划
- [ ] 5 只要分析，不改码
```

## 收尾卡（修完后）

```markdown
# Bug 收尾

- 实际执行范围：点 / 线 / 面 / 发散覆盖
- 落地：本会话 | go-fast `spec_ref=`
- 主层是否仍成立：
- 验证结果：（含换皮抽检）
- 未关闭的线/面/发散债：
- 防复发已落地：
```
