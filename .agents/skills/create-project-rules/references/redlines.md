# 生产交付红线（写入目标仓 rules 的强制条款）

本文件是生成/体检 `.cursor/rules` 时的**红线真源**。Agent 须把下列条款落到目标仓规则。**禁止**软化、改成「建议」或「可选」。

参考仓（ark / nex）只学**结构与表达层次**，不得复制其产品名、路由、PRD ID、进程名。

构建产物/制品上传的**操作步骤**不在本文件展开，见姊妹 skill **release-package**（及 deploy-dev）；此处只保留门禁红线（R18）。

---

## R1 · 会话启动必读

1. 读 `docs/arch.md`
2. 读 `docs/automate/goal.md`
3. 扫顶层目录，核对与 arch 是否漂移

缺文件 → 标 `（缺真理源）`，引导 create-evolution-arch / goal；**禁止**臆造架构写入 rules。

---

## R2 · 日志规范

分级 Info/Error/可关 Debug；**按大小或时间滚动** + 保留 N 个或 T 时长；分类：请求 / 进程 / 作业；统一 mask；禁 `print`/`console.log` 当生产日志。

---

## R3 · 高可用与单机切换

配置支持**单机**与 **HA**；切换不靠改代码；锁/选举/共享存储写清；readiness/liveness；禁止「多开即 HA」。

---

## R4 · 多数据库（强制）

可切换落地：`sqlite` | `mysql` | `postgres`。统一驱动；关键路径三类可验证（或缺测记债务）。

---

## R5 · 外部认证源（强制）

**LDAP** + **OAuth/OIDC**（+ 所需本地登录）。可关；IdP 失败≠静默放行；进管理面；禁开发万能身份进生产。

---

## R6 · 运行时配置：库内 + 热改（有 Web 管理面）

yaml/极少 env 仅：监听角色、DB/缓存/MQ 连接、根密钥、进程日志。其余进 **DB + 管理面热改**。禁长串业务 env。

---

## R7 · 用户可见文案（人话）

小白视角；禁 PRD 编号、甲乙方、你方；错误优先人话。

---

## R8 · UI / 设计规范优先

有 FE：先 `docs/ui/`，再设计 skill；无基准先补，禁自由发挥。

---

## R9 · 数据库迁移 · 种子 · 表定义（强制）

**能力**（路径按栈，见 [db-layout.md](db-layout.md)；勿盲抄 `db/`）：

| 能力 | 要求 |
|------|------|
| migrations | 每次 schema 变更有版本化迁移；久未升可顺序重放；破坏性变更有策略 |
| seed | 平台幂等种子；与可选 demo 种子分离；**demo 默认不进生产启动** |
| 表定义 | DDL / ORM schema / 生成 model 等真源明确；文档进 `docs/data/` |
| bootstrap 管理员 | 允许首装默认账号（如 `admin`/`admin`）；**首次登录或等价流程强制改密**；生产禁长期弱口令 |

go-zero 常见：`db/migrations` · `db/seed` · `db/ddl`+`db/model`。Prisma/Django/Alembic 等用生态惯例路径。

---

## R10 · 工程质量补充

假绿零容忍 · 契约优先 · 密钥不进 git · 审计+request id · 管理/业务面分离 · 关键路径有测 · 交付诚实。

---

## R11 · 体量与生成物豁免

函数 ≤120 行；手写文件 ≤300 行；同目录 ≤10 个文件。**codegen/框架产物不计入**；禁手改生成物冒充源。

---

## R12 · API 信封（强制）

`{ "code": 0, "msg": "ok", "data": ... }`。统一封装；例外（下载/SSE）须标明。

---

## R13 · 分层与复用上浮

接口薄 → **service/\<domain\>** → 持久化/ACL。第 2 处同域逻辑上浮；无状态进 pkgs/lib；前端进 components。

---

## R14 · 工程文档可消费深度

`docs/api` / `domain` / `service` 达可消费深度；重大事故有 runbook（可先写在 service 运维节）。

---

## R15 · 国密密码学（强制）

业务侧加解密 / 签名 / 摘要默认国密：

| 用途 | 算法 |
|------|------|
| 对称 | **SM4** |
| 摘要/HMAC | **SM3** |
| 非对称/签名 | **SM2** |

无 ADR 不得把 AES/RSA/SHA-2 等作业务主路径；外部只支持国际算法时 ADR + 适配器隔离；统一 crypto 封装；密钥分槽与轮换成文。

---

## R16 · 弹性与幂等（P0）

出站/DB/MQ **显式超时**；重试仅幂等+退避上限；API **限流/配额**；外部依赖失败有熔断/降级/快失败（禁假成功）；易重复写操作 **幂等键或 409**。

---

## R17 · 指标与链路（P0）

RED（或等价）指标 + 队列积压（有 job 时）；request/trace id 贯穿日志与出站；关键告警有归属。**有日志 ≠ 已观测。**

---

## R18 · 交付门禁指针（P0）

| 细则在 | 本规则只钉 |
|--------|------------|
| **release-package**（构建产物、打包装、上传 S3） | 禁无版本手工拷贝当生产交付；禁 AK/SK 进仓 |
| **deploy-dev**（演示机部署） | 宣称可交付前：约定测试/smoke 绿、无假绿、迁移可重放 |
| **create-dev-config**（**仓库** `.dev`） | 本项目运行/走查/release·deploy 登记；`docs/service` 含**回滚上一版本** |
| **create-home-dev**（**家目录** `$HOME/.dev`） | 外部集成验真选源；AGENTS/delivery 须有双 `.dev` 指针；台账不入库 |

---

## R19 · RBAC 与审计（P1）

角色权限可配；敏感写必审计（谁/何时/对象/结果）；高危操作后端二次确认（不单靠前端）。

---

## R20 · 密钥与加密分级（P1）

根密钥 / DEK / 传输凭证 / 可轮换业务密钥分档；落库敏感字段加密（算法见 R15）；支持轮换；危险默认可拒启。

---

## R21 · 异步作业契约（P1）

有 worker/队列：任务幂等；失败可重试 vs 死信可观测；作业日志关联业务/请求 id；禁 API 内无界长任务（除非 arch 允许）。

---

## R22 · 测试门禁矩阵（P1）

| 层 | 何时必有 |
|----|----------|
| 单测 | 新 service/关键逻辑与错误分支 |
| 集成/API | 新路由主路径 + 失败语义 |
| 外部 smoke | 新接 IdP/厂商：真打或沙箱留证；端点/变量名优先 `$HOME/.dev`，项目侧对齐仓库 `.dev` `integrations` |
| 合入 | 约定 CI/`make test` 须绿 |

禁止无测试合入关键路径；禁止为 smoke 编造未登记的外部端点。

---

## R23 · 备份与保留（P1）

备份方式与 RPO/RTO 成文；审计/日志/业务保留周期可配或成文；有恢复步骤指针。

---

## R24 · 前端性能与无障碍（P1）

加载/失败态明确；列表分页禁无界拉取；表单错误关联字段；图标按钮可达名；细节见 fe-ui + docs/ui。

---

## R25 · 多租户隔离（P2 · 有多组织/SaaS 时强制）

租户 id 贯穿读写；禁串租；跨租管理须显式授权。单租户产品须在 arch 标明。

---

## R26 · 合规 / i18n / 边缘 / 供应链（P2 · 按形态）

| 主题 | 何时 | 要点 |
|------|------|------|
| 等保/过检 | 合同要求 | R15+R19；必要时 docs/security |
| i18n | 多语言 | 文案可扩展；默认语言成文 |
| 边缘 Agent | 有独立 agent | 不 import 控制面 internal；独立配置升级 |
| SBOM/许可证 | 外发交付 | 跟 **release-package** 流水线；产物可追溯，禁无清单外发 |
