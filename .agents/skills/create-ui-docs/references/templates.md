## 页头形态（全站统一 · 必填）

从标杆页抽样判定，**整站只选一种主形态**（例外页须在 IA 注明）：

| 字段 | 取值 |
|------|------|
| **形态** | `title-card`（独立标题卡：圆角/浅底表面内 = **左** icon+标题+说明 · **右** 操作区）· `flush`（非卡式标题区，操作仍可在右侧）· `minimal`（仅标题；少见） |
| **共享组件** | 路径（如 `RepoPageTitleCard` / `PageHeader` / `ConsolePageTitle`）；无则写「待 S0 抽取」 |
| **必含元素** | icon？ · 标题 · description？ · **actions（右侧）**？ |
| **操作区约定** | 本页有主任务入口时：**标题卡/页头右侧必须能放按钮**（主 CTA 实心 primary 1 个；次要 outline/ghost；危险勿与主 CTA 并列抢视觉）。禁止把「新建/从模板创建」等主操作只塞进表工具栏而页头空右侧（若标杆是右操作式）。 |
| **抽样标杆** | ≥2 个同形态页路径（证明是全站习惯，不是单页偶然） |
| **可信度** | confirmed / inferred / assumed |

**禁止**：全站已是 `title-card` 却生成裸 `h1`/无说明/无右侧操作（标杆有操作时）；全站已是 `flush` 却硬套一层标题卡；把页头标题卡算进内容区套卡反模式。
