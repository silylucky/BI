主导航、关键区；与路由表对应关系。

| 路由 | 菜谱（列表/详情/设置…） | 标杆页 | 备注 |
|------|-------------------------|--------|------|
| … | … | … | … |

## 设计约定
Token / 共享壳位置；链到设计系统或 ui-ux-reviewer 标杆。

## 权限表面
无权限时的表现（隐藏 / 禁用 / 诚实空态）。

## 非目标

## 相关
domain / api 链接；深扫用 ui-ux-reviewer。
