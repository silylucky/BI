# 交稿自检清单

成稿后逐项勾选；任一项未过不得宣称「可终验」。

## 结构

- [ ] 章节号 / 标题字面与模板目录一致  
- [ ] 小节标题名与同文档标杆一致（非自创「接口要点」结构）  
- [ ] 无标杆外尾巴章（错误码附录、修订说明、补充机制…）  
- [ ] 需求类：系统功能下有可进目录的功能点叶子（若模板要求）  
- [ ] 未擅自改已完成标杆章  

## 内容与证据

- [ ] 正文能力均有代码/配置/界面证据支撑（内部笔记可查）  
- [ ] 无证据能力整段已省略或已做映射覆盖（无「待确认」占位）  
- [ ] 无自我暴露缺口、无未交付对端点名  
- [ ] 无 mock/联调替身写入生产能力清单  
- [ ] 跨文档同模块能力同源、粒度符合文档类型  
- [ ] 指标 / SLA 仅有据数字或证据口径  

## 文风与称谓

- [ ] 无「我方 / 甲方 / 你方 / 贵方 / 我们 / 你们」  
- [ ] 可预读：无大片路径 / 错误码 / 函数方法名 / 反引号标识符刷屏  
- [ ] 专名与目录一致  

## 版式

- [ ] 列表、表格用法与标杆一致或已按 format-optimization 优化  
- [ ] 对接表 / 库表列名与模板一致  
- [ ] 无重复段落改序号凑篇幅  
- [ ] 无双重编号（手写章号 + 样式自动编号）  

## 图与截图

- [ ] 技术方案/详细设计（标杆有图时）：每模块有流程图 + 组成/架构图  
- [ ] 界面节：真机截图或 MANIFEST 诚实标注未截/部分  
- [ ] 图框内无 API/表名/函数名  
- [ ] 非假 UI  

## 交付

- [ ] 落盘路径明确；有合并管线已重合并  
- [ ] 抽检目录层级与「插图未找到」  
- [ ] 代码依据清单若提供则与正文分离（默认不进 Word）
