# 前端 UI 契约（go-fast · 复用真源）

做前端时 **不要**在 go-fast 里另写一套视觉规范。  
**真源（按序 Read，冲突时以下方「硬清单」与 craft 为准）**：

| 优先级 | 文件 | 管什么 |
|--------|------|--------|
| 1 | 仓内 `docs/ui/`（`anchor.md` + `layout.md` + 菜谱） | 本仓锚与标杆 |
| 2 | [create-ui-docs/references/craft.md](../../create-ui-docs/references/craft.md) | 密度 · Dialog/Sheet/独立页 · **详情只读** · **禁套卡（含列表外卡套表内框）** · 文案 · 抛光 |
| 3 | [ui-ux-reviewer/references/page-recipes.md](../../ui-ux-reviewer/references/page-recipes.md) | 菜谱 A–F、CRUD 承载、**行操作 ghost**、列表一层表面 |
| 4 | [ui-ux-reviewer/references/anti-patterns.md](../../ui-ux-reviewer/references/anti-patterns.md) | 反模式（套卡、详情直接表单、行内实心钮、删除同色等） |

`ui-ux-reviewer` 是**评**这些规则；go-fast / implementer 是**写页时遵守**同一套。禁止 fork 出第三份「差不多」的规矩。

开工改前端时：主编排 Read 上表 → 把本页结论填进 [implementer-prompt.md](implementer-prompt.md)「UI 契约」；实现者**禁止**只收到「跟仓内风格」四个字。

## 硬清单（须下传 implementer · 与用户口径对齐）

### 1. 详情默认只读（craft §7 · 菜谱 E）

- **已有资源详情**：优先 **只读描述**（DescriptionList / 只读字段），**不要**一进页就是满屏可编辑表单。  
- 「编辑」按钮之后才进入可改：同页 edit mode / Sheet / 独立编辑路由（跟同域标杆）。  
- `/new` 除外，可直接表单。

### 2. 编辑载体选型（craft §2 · 菜谱 CRUD 表）

点「编辑」时，**显式选定一种**并写进 UI 契约（同域一致）：

| 场景 | 优先 |
|------|------|
| ≤5 简单字段 | **Dialog** 或 **Sheet（抽屉）** |
| 中等表单、要瞥见背后列表 | **Sheet / Drawer** |
| ≥8 字段、多步、需深链 | **独立页面** 或 Wizard |
| 删除 / 不可逆 | **AlertDialog**；触发控件 **destructive 红** |

禁止同域新建/编辑有的弹框、有的整页、无约定。

### 3. 危险操作配色（反模式 · 语义色）

- **删除 / 移除 / 销毁** 等危险操作：**红色 destructive**，不得与「编辑」同用品牌主色。  
- 列表/工具栏里：**不能全部按钮都是品牌色**；主 CTA 最多一颗 solid，其余 ghost / outline；危险专用红。

### 4. 列表操作栏（菜谱 B）

- 行末「操作」列：**一律幽灵按钮（ghost）**——无实心底、hover 浅底。  
- **按钮组间距要紧凑**（跟标杆/`Button` group；禁止操作列里大块空隙把 2～3 个 ghost 撑得很开）。  
- ≤4 平铺；>4 → `…` 菜单；删除红 + 确认。  
- **禁止**行内实心 Primary / 品牌色钮一排。

### 5. 页内色彩密度（craft §1 / §6 · 反模式）

- **色彩不要过度密集**：禁止装饰性大面积色块、图标墙、卡片顶边狂涂品牌色、状态全刷成主色。  
- 语义靠轻底 / 小图标 / 文案；状态分色（成功/警告/危险），**禁止**「全都是品牌蓝」。

### 6. 禁止卡片套卡片（craft §6 · 反模式 · 列表极常见）

- **一层**表面承载主内容；内部分区用 `gap` / 细分割线 / 分组标题，**不要**靠再套一张 Card 制造层次。  
- **列表页禁例（须认）**：外层白底圆角卡（含搜索/筛选）内，再套一层带边框圆角框包住「表头 + 行 + 分页」→ **套卡**。应筛+表+分页同层，表区**无**第二描边框。  
- 亦禁：大卡套并排步骤小卡；内容区再套带边框提示条卡。  
- **不算套卡**：`layout.md` 约定的页头 `title-card`（壳层）。  
- **分层 ≠ 套卡**：工具栏与表要分区时用同表面内分割，禁止「外 Card + 内 Table Card」。

### 7. 与评审的关系

- 收尾 / loop 的 `ui-ux-reviewer` **按同一真源打分**；实现阶段已遵守 → 少返工。  
- 纯视觉口味债仍可进 ui-ux；本清单属**任务/可发现/误触**级，go-fast 前端片 **必须**落地。
