# Fake / Mock：只在系统边界

**只替换你不控制的边界**；不 mock 自己的内部模块。

## 可以替换

- 下游 HTTP / gRPC / 厂商 SDK
- 外部 DB（若 seam 是端口；优先测试库而非 mock 一切）
- 时钟、随机数、文件系统（当行为依赖它们时）

## 不要替换

- 本模块内部类/函数/未导出协作
- 「整个应用」一层假的成功适配器（假绿）
- 仅因「好测」而引入的巨型万能接口

## 用法：小接口 + 注入

在**使用方**定义窄抽象，构造时注入；测试用手写 fake 通常足够，不必默认上生成器。

```text
接口 Charger { Charge(金额) -> 支付单号 }

结账服务.pay = Charger

结账(cart):
  id = pay.Charge(cart.总额)
  返回 订单{支付单号: id, 状态: 已确认}

测试 fake: Charge 固定返回 "pay_1"
断言: 结账后状态=已确认 且 支付单号=pay_1
```

## 偏好专项方法，而非万能 Do(path)

```text
好: GetUser(id) / ListOrders(userId)   — fake 无分支
坏: Do(path, body)                     — fake 里一堆 if path
```

## 与生产代码的边界

| 位置 | 允许 |
|------|------|
| 测试文件 / 测试 harness | fake、stub、内存 store |
| 非测试主路径 | **真实实现**或明确未接线（失败/未实现）；禁止固定成功占位 |

外部依赖**契约不明**时：停手走契约不明门（research → 八维择优 → 真接，或 park）。  
**禁止**在业务主路径用 stub/mock/假成功顶替；测试里的边界 fake **不等于**交付完成。
