# 八维细则与锚点

每维先按子项 0/1/2（无= N/A 不计入），再换算为 0–100：

`维分 = round(100 * 所得 / (2 * 计入子项数))`

证据：引用文档标题/小节 + 短引语，或「缺失」。

---

## 1. 最佳长远规划

| 子项 | 2 | 1 | 0 |
|------|---|---|---|
| 终局 vs 首版 | 首版范围小但终局方向清楚 | 有方向但混淆临时/终局 | 临时态写成终局或无演进 |
| Out of Scope | 明确排除假交付与非目标 | 有 Out 但软 | 无边界 |
| 依赖演进 | 外部/平台依赖有接入或退出策略 | 点到但无策略 | 假设依赖永不变 |
| 决策可逆性 | 难回退点有记录或 ADR 指向 | 有取舍无记录 |  silently 锁死选型 |

## 2. 最佳产品体验

| 子项 | 2 | 1 | 0 |
|------|---|---|---|
| 用户任务闭环 | 主路径从触发到结果可讲述 | 只写功能点无任务 | 无用户视角 |
| 入口完整性 | 有能力必有入口计划 | 部分入口 | 能力无入口或入口半成品被接受 |
| 空态/错误/权限 | 方案覆盖关键态 | 仅提主路径 | 忽略失败与空态 |
| 一致性 | 与现有产品壳/模式对齐 | 部分对齐 | 另起一套体验语言 |

## 3. 最佳生产诚实

| 子项 | 2 | 1 | 0 |
|------|---|---|---|
| 验收真实路径 | 点名真实依赖与可观察结果 | 真实但含糊 | 允许 mock/demo 通过 |
| 完成定义 | 「已实现」= 真可用 | 混用部分实现 | 骨架/假数据算完成 |
| 失败诚实 | 依赖不可用不得假成功 | 有错误无策略 | 降级仍返回成功 |
| 宣称一致 | 文档宣称 ≤ 可兑现 | 略超前 | 宣称与计划矛盾 |

**硬门槛常落此维。**

## 4. 最佳架构边界

| 子项 | 2 | 1 | 0 |
|------|---|---|---|
| 模块/进程边界 | 职责与禁止跨界清楚 | 有图边界糊 | 无边界 |
| 数据归属 | 真理源明确 | 多处可写未裁定 | 未讨论 |
| 缝与适配 | 外部经清晰端口 | 部分直连 | 领域核心绑死厂商 SDK |
| 取舍追溯 | 关键决策有因/备选 | 只有结论 | 无决策 |

## 5. 最佳可靠性

| 子项 | 2 | 1 | 0 |
|------|---|---|---|
| 超时/重试/幂等 | 写清适用范围 | 口号式「要可靠」 | 未提 |
| 部分失败 | 有补偿/界限 | 含糊 | 忽略 |
| 容量/退化 | 有可感知降级 | 仅扩容幻想 | 无 |
| 测试策略 | 测行为/契约，非实现耦合 | 提到测 | 无或鼓励假绿测 |

## 6. 最佳可运维

| 子项 | 2 | 1 | 0 |
|------|---|---|---|
| 部署与环境 | 环境差与发布方式清楚 | 仅「能部署」 | 无 |
| 配置与密钥 | 非密/密分离，轮换意识 | 有配置无密钥纪律 | 明文或未提 |
| 观测 | 日志/指标/追踪至少有计划 | 单点 | 无 |
| 回滚/值班 | 有回滚或应急 | 含糊 | 无 |

## 7. 最佳安全合规

| 子项 | 2 | 1 | 0 |
|------|---|---|---|
| 认证授权 | 模型与边界清楚 | 只写「要登录」 | 无 |
| 密钥与敏感数据 | 存放与访问约束 | 部分 | 忽视 |
| 审计 | 关键写操作可追 | 计划弱 | 无 |
| 威胁/合规 | 点名约束或 N/A 有理 | 套话 | 高风险域却空白 |

## 8. 最佳交付可验证

| 子项 | 2 | 1 | 0 |
|------|---|---|---|
| 切片独立性 | 每片可单独真实验收 | 片过大过碎 | 不可验收 |
| 依赖/阻塞 | 序清楚 | 部分 | 无序或循环 |
| 成功指标 | 可判定且非「能演示」 | 方向性已标注 | 主观不可测 |
| 对照门禁 | 与 goal/prd/plan 可对账 | 松散链接 | 三套各说各话 |

## 文档类型侧重（加权提示，非改公式）

| 类型 | 多看 |
|------|------|
| goal | 1、3、8 |
| prd | 2、3、8 |
| arch | 4、5、6、7 |
| plan | 1、3、8 |
| adr / brief | 4、5、3 |
| design-doc | 2、4、8 |

仍八维都打分；侧重只影响证据收集优先级。
