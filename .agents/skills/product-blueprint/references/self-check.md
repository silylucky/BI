# 确认前自检（强制）

进入 Phase 5「请确认」或宣称成稿可确认前，主编排逐项勾选。任一 ❌ → 先修，不得请确认。

## A. 图与叙事

- [ ] 有 1 张架构关系图（Mermaid 可渲染）
- [ ] 每个**核心**主业务 F 各 1 张流程图；清单与图 id 对齐
- [ ] 核心 F 数量 ≤5；超出已进「附录流程」且确认包不展开附录全文
- [ ] 图节点用人话；与正文主路径步骤名/角色一致
- [ ] 每张业务图含 ≥1 条关键失败/驳回出口
- [ ] `audit`：图标明 as-is；若有改造建议则有 to-be 或注释区分

## B. 场景与领域

- [ ] 用户场景对照表非空；无「纯实验室步骤」冒充主路径
- [ ] 领域席已独立回传（或合法缩席说明里**不可**省略领域席）
- [ ] 对照表「依据」可点到证据袋路径或公开来源
- [ ] `domain_strength=weak` 时：假设醒目，且不得无人值守伪 `DONE`（须 `DONE_WITH_CONCERNS`）

## B2. 难回退选型（见 [selection-gate.md](selection-gate.md)）

- [ ] 证据袋含 `selection_constraints`（无则明示「本 scope 无难回退选型」）
- [ ] 无 `open` 约束仍被画进已定主路径；`open` 存在时未请确认伪 `DONE`
- [ ] `assumed` 已进确认面假设并标「难回退选型」
- [ ] `researched` 有简报路径；契约不明未编造协议
- [ ] 架构席已回传 `selection_ok`（或合法 N/A：无新边界且无新选型）
- [ ] 依赖选型的图在约束状态更新**之后**定稿（非先图后选型）

## C. 确认面 vs 落盘

- [ ] 对话确认面仅含精简项（见 SKILL Phase 5）；未把完整成稿墙贴进聊天
- [ ] 完整成稿已写或将写到约定路径；确认面给出路径
- [ ] 假设清单在确认面醒目；未写成已裁定

## D. 生产诚实

- [ ] 无可观察验收 = mock/stub/demo 句
- [ ] 主路径 + 例外/逆操作 + 权限 + 审计（适用时）均有
- [ ] 有 UI：页面说明禁外卡套表格；有 `docs/ui` 则引用菜谱/锚而非重发明壳

## E. 智囊团

- [ ] 提纲阶段有独立 Task 席位回传（非一人分饰）
- [ ] 合并说明含每席 vote + must_fix 处置
- [ ] 无未消 veto
- [ ] 成稿轮按增量规则派席或写明 skip

## F. mode 特例

- [ ] `blueprint`+PRD：偏航对照表已备（或注明无 PRD 锚）
- [ ] `spec`：开工就绪字段齐全（见 [spec-map.md](spec-map.md)）；将跑/已跑 `go-fast-spec-gate`
- [ ] `audit`：缺口严重度表已备；未冒充 product-reviewer 八维分

## G. 术语

- [ ] 术语表覆盖图中主标签与确认面关键名词（或 scope 极简已注明 N/A）
