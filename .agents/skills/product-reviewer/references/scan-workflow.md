# 取证工作流（刁钻产品）

目标：刺点可复核，方案可切片；不是写「产品感言」。

## 1. 定范围与角色

1. 写下级别：`system` / `flow` / `module` / `page`。  
2. 点名主角色（至少一）：如「业务经办」「审批人」「管理员」「审计」。未知 → Card 标待确认，评分降置信。  
3. 列出 **1 条主 JTBD** + 最多 **2 条次任务**（多了就说明范围太大，先收缩）。

## 2. 找入口与真源

| 找什么 | 哪里 |
|--------|------|
| 导航入口 | `*nav*`、侧栏、路由表 |
| 页面/向导 | `pages/`、`views/`、路由 component |
| 状态与动作 | API 名、domain 状态枚举、按钮文案 |
| 权限 | RBAC 配置、菜单可见性、按钮 disable 原因 |
| 产品文档 | `docs/domain`、`docs/ui`、帮助中心（口径冲突要记刺点） |

有 `docs/ui/*-ia.md` → 先读菜谱与标杆，再对照实现是否「有菜谱无任务」。

## 3. 走主路径（纸面或真机）

逐步记录：

```text
步骤n: 用户动作 → 系统反馈 → 业务状态变化 → 下一入口
```

卡点类型标记：`迷茫` / `多余步骤` / `不敢点` / `点了没结果` / `结果不可信` / `系统无此步`（后者优先走 `capability_gap`）。

有 `.dev` 与剧本时，可接力 [browser-reviewer](../../browser-reviewer/SKILL.md) 截主路径；没有则代码+文案推演，并在报告标明「未真机」。

## 4. 刁钻用例清单（按对象抽测）

至少覆盖与级别相关的子集：

| 用例 | 问什么 |
|------|--------|
| 空租户/无数据 | 能否理解下一步？ |
| 权限不足 | 表面是否诚实？ |
| 校验失败 | 是否指到字段/对象？ |
| 提交后失败 | 是否可重试？数据半成品吗？ |
| 驳回/撤销 | 发起人能否看见原因与再提交？ |
| 双人同时改 | 谁赢？是否提示？ |
| 过期/失效对象 | 仍展示可点吗？ |
| 跨模块跳转 | 上下文是否丢失？ |
| 只读审计角色 | 能否完成「查清责任」而不误操作？ |

每个触发的失败 → 记刺点（维 3/4/6 常中招）。

## 5. 状态一致性抽检

抽 1～3 个写操作：

1. 操作前列表/详情快照（字段关键值）  
2. 操作  
3. 操作后列表、详情、若有外部副作用（任务/消息）是否一致  

不一致 → 维 6 重扣；若成功提示但未变化 → 硬门槛。

## 6. 「绕过系统」探针

问：用户是否会用 Excel、IM、口头审批绕过？  
若代码/文案显示大量「线下已确认再来补录」且无约束 → 维 1/8 扣分，方案里写清是**收口**还是**正式支持补录**。

## 7. 方案切片纪律

每个 P0/P1：

1. **用户可感知变化**（一句话）  
2. **验收**：谁用什么步骤能验证修好  
3. **证据路径**：路由/文件/API（给 go-fast 白名单）  
4. **不做**：明确不碰的模型/邻域  
5. 若需改 RBAC/路由模型 → 标「需产品裁定」，勿在本 Skill 直接实施  
6. 标注 `硬门槛` / `视觉债`（是/否）  
7. 标注 **分类**：`experience_fix` / `capability_gap` / `out_of_scope`（见 [capability-gap.md](capability-gap.md)）  
8. 主路径/例外「系统没有这一步」→ 优先考虑 `capability_gap`，补齐强制字段，勿只写体验空话

## 8. 报告前检查

- [ ] 主 JTBD 已写清  
- [ ] 八维均有证据句（本轮取证，非抄旧报告）  
- [ ] 评分未锚定历史落盘分 / 目标分；接受可为降分  
- [ ] 无「加个提示就好」冒充 P0 产品方案  
- [ ] 硬门槛已检查且每条挂刺点 ID  
- [ ] 每条刺点已标分类；处理清单含硬门槛/视觉债/分类列；刺点证据含可解析路径  
- [ ] **穷尽**：主路径/刁钻用例触发点已全列；无「代表样例」截断；必要时二次 sweep  
- [ ] 有 `capability_gap` 则「体验依赖能力清单」已填强制字段；列出缺口未抬分  
- [ ] 再评已继承上轮清单（未清空 ID）  
- [ ] 未真机已声明  
- [ ] 建议按 P0→P1→P2 排序；缺口类方案指向 PRD/蓝图而非假装本环已落地
