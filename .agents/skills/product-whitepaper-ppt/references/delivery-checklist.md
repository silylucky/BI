# 交稿清单

## 内容（白皮书口径）

- [ ] 页数 ≥30；含亮点、**产品级**架构、≥2 业务场景、收束
- [ ] 亮点是用户收益句，不是模块名墙
- [ ] **无** Cookie/Header/中间件类名/ADR 编号/`code===0`/函数调用链作正文主句
- [ ] 架构页能给技术决策者「可信」感，但不像在读 arch.md
- [ ] 架构总览 / 拓扑页 role 为 `relationship` 或 `breakdown`（**不是** metrics）
- [ ] 定位 / 边界页为 comparison 或 breakdown，**两侧各 ≥3 条**具体 In/Out（**不是**空象限图）
- [ ] 无写作提示残留（「定位一句话」「待补充」等）
- [ ] 部署页无人话以外的 CLI / `--role=` / 包路径作主文案
- [ ] 业务流节点是角色与业务动作
- [ ] 无编造指标；`（推断）` 已列出；拓扑/边界页无假「强度/成熟度」分数
- [ ] outline 有 `sourceRefs`（自检用，未必印在页上）

## 渲染（正式稿）

- [ ] 使用 **dashiai-ppt** 渲染（非自制 HTML 冒充）
- [ ] `goal.json` + `ppt/index.html` 在 `docs/material/<slug>/`
- [ ] 预览可翻页；无大面积模板默认文案残留
- [ ] **已做视觉抽检**（封面 / 定位边界 / 架构总览 / **场景总览+步骤详解** / 路径 / 流程 / 结尾）
- [ ] 无叠字、无字段粘连、**无空坐标/空象限撑版**
- [ ] **无步骤列复制粘贴、无卡片标题撞名、无流程假 %、无 bump-rank/估值座次冒充步骤**
- [ ] **无「影像 N / 点击上传」空图槽**（无素材则已换无媒体页或 `imageSlotCount: 0`）
- [ ] **标题可朗读、无词中切开、无半截截断**
- [ ] 架构或边界或场景页不合格已换 layout 返工，未硬交
- [ ] 需要 PDF/PPTX 时已用 dashi export 落到 `export/`

## 降级稿（仅用户接受时）

- [ ] 回复中明确写「降级自制 HTML，效果不及 dashi」
- [ ] 仍提供 outline/slides 便于改走 dashi

## 回复必含

1. `docs/material/<slug>/` 路径  
2. 主题 pack + 页数 + 两场景名  
3. dashi 预览 URL 或 PDF/PPTX 路径  
4. 推断项  
5. 视觉抽检结论（通过 / 哪几页已返工）
