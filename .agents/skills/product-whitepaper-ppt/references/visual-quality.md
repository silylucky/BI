# 视觉质量

正式交付的视觉质量由 **dashiai-ppt** 主题与版式保证，不在自制 HTML 上「微调到能看」。

## 正式稿

- 必须经 dashi `render_goal_deck` 产出  
- 只填文案 props；流程用 process 版式的步骤/条目字段表达  
- 异常用 risks 类版式的结构化条目，禁止把 Markdown 表原文塞进单字段  
- 交付前按 dashi 规范做 copy 校验；**必须**抽查封面、目录、定位/边界、架构、一页路径、一页流程、结尾  

## 出片后视觉闸（正式交稿前必做）

打开预览，对下列页**逐页看图**（不要只读 `goal.json`）：

| 抽检页 | 不合格即返工的信号 |
|--------|-------------------|
| 封面 | 大面积模板默认文案、标题截断 |
| **定位 / 产品边界** | **空坐标/空象限**；只剩 IN/OUT 轴标签；标题仍是「定位一句话」等写作提示；In/Out 无具体条目 |
| **目标用户 / 分栏配图页** | **「影像 N · 点击上传」空槽**；右侧空白占一半版面却无图 |
| **怎么读 / 决策者 / 大标题页** | 标题词中切开；长句乱折行；正文截成半截（「规划独…」） |
| **大字主张页** | 巨字占半屏、每行 >12 字、把痛点长句写进 `lines` |
| 架构总览 | 叠字；字段粘连；折线/雷达冒充拓扑；CLI/`--role=` 上屏 |
| 部署 / 角色 | 启动参数当主标题；名字与角色糊成一串 |
| 同步/异步路径 | 包路径、中间件名作步骤主标签 |
| **场景总览** | 大字叠字遮挡；多卡标题撞名（多个「活动告警」）；无来源的假 % 条 |
| **场景步骤详解** | **≥3 列正文相同**；底栏价值点也复制同一句；每步都是同一句基建黑话；**排位/bump 图 +「估值口径」脚注** |
| 任一流程页 | 步骤为空、或一整段 Markdown 糊进单框 |
| **任一图表页** | 数据点 <3、全 0、或主视觉 >50% 空白只靠轴/图例撑场 |
| 结尾 | 占位 slogan 未替换 |

### 「空页」判定（一眼废）

出现任一条即不合格：

1. 主视觉区域大面积空白，信息密度明显低于同主题其他页  
2. 坐标轴/象限框在，但没有可读的能力点、对比行或列表  
3. 可见写作提示或未替换占位（`定位一句话`、`标题`、`待补充`、英文 lorem）  
4. 用假维度（「复杂度×价值」等）画空图，真实边界文字却挤在页脚一行  

处理顺序：

1. `inspect:layout` 确认字段形状是否匹配该页意图  
2. 不符 → **换 layout**（同 role 另选），重填短文案  
3. 同 layout 微调无效（结构错了）→ 不要死磕 props  
4. 空边界页 → 改 `comparison`/`breakdown`，两侧写满具体 In/Out  
5. 步骤列复制粘贴 → 按「选谁/拦什么/谁批/谁跑/证据落哪」重写每列，删假 %  
6. 叠字 / 卡片撞名 → 换 process/breakdown layout，缩短主句，保证标题互异  
7. **排位/估值 bump 图当步骤**（可见「估值口径」「1=最高」或左右标签糊成乱码）→ 立刻换 `roadmap`/步骤面板，删除全部 `ranks`  
8. **空图槽** → 换无媒体 layout，或 `media:stage` 补真实图；禁止留「点击上传」  
9. **标题乱断/截断** → 缩短主张或按 `titleL1/L2` 意群预拆；朗读不通则换版  
10. 同一页最多返工 2 轮；仍差 → 降为「结构已交、该页待换版」，**不得**当正式白皮书页交付  

## 自制 HTML

- 仅 fallback  
- 即便修了表格渲染，也**不得**称为与 dashi 同级效果  
- 见 `scripts/build-html-deck.mjs`（降级用）

## Agent 自检

问自己：若用户并排打开「直接 dashiai-ppt」和「本 Skill 成品」，视觉是否同级？  
否 → 说明没用 dashi，或 props 填坏了模板——返工，不要交自制页。

再问：架构总览是否像「一张能讲清的产品拓扑」，而不是「一张塞满工程词的假图表」？  
否 → 换 `relationship` / `breakdown`，删假数值。

再问：定位/边界页读者能否念出「做什么 / 不做什么」的具体条目，还是只看到空轴？  
否 → 换 comparison/breakdown，删空象限。

再问：场景步骤页五列念出来是否五句不同的事？  
否 → 复制粘贴废页，按 flowchart-spec 重写后再渲染。

再问：有没有「点击上传」空框？标题朗读是否通顺完整？  
否 → 换无媒体页或补图；修断行/截断后再交。
