# Page Recipes（菜谱矩阵）

上线前先给每页贴菜谱，再按菜谱对齐**本仓标杆**，避免每页私设一套壳。名称 A–F 可改，**结构勿丢**。

## 如何选标杆

1. 用户点名 → 锁定。  
2. 否则在同产品里找：**页头完整、工具栏分层、空态有 CTA、CRUD 闭环** 的 1～3 页。  
3. 若有 page-craft / design-system skill 或 `components/ui` 文档 → 标杆 + 系统规范双约束。  
4. 标杆写入 FE Card；扫描与修复时**只读**（除非回归）。

## 菜谱

| ID | 名称 | 适用 | 对齐要点 |
|----|------|------|----------|
| **A** | 概览仪表 | overview / health / coverage / panorama / 首页摘要 | KPI 色调表面；可深链；无假数；空/错态完整 |
| **B** | 资源目录 | 列表 / 队列 / 规则 / 作业 / 归档 | **页头**（跟 layout：title-card 则左身份右操作）+ **一层**主内容（工具栏 → 表 → Pagination；分区用 gap/分割线，**禁止**外卡再套表格内框）+ **行操作 = ghost**（下表） |
| **C** | 作用域工作区 | 先选对象再 Tab（树节点、租户、项目） | 作用域铬条稳定；Tab 内套 B/E，勿每 Tab 另起页头体系 |
| **D** | 主从树+详情 | 设施树、拓扑、联邦、目录树 | 左树右详密度对齐标杆；空选态有引导 |
| **E** | 详情 / 新建 | `/:id`、`/new`、长表单 | **已有资源默认只读**（DescriptionList）+「编辑」才可改；`/new` 可直接表单；Form 壳+分组；提交/取消明确；副标题/hint **用户向**（禁内部码） |
| **F** | 规则 / 表达式 | 规则、表达式、静默、日程、策略 | 列表用 B；编辑按字段量 Sheet 或 Wizard；禁 Dialog 塞超长表 |

**扩展**：图表监控墙、看板编辑器、双栏对比等 → 新建菜谱行，仍须满足四维验收 + 反模式。

## 页头（全站 · 读 `docs/ui/layout.md`）

| 检查点 | 通过标准 |
|--------|----------|
| 形态 | 与 layout `title-card` / `flush` / `minimal` 一致；混用无理由 → P1 |
| 标题卡结构 | `title-card`：**左** icon+标题+说明；**右** 操作区（标杆有按钮则本页须有槽） |
| 右操作层级 | 主 CTA = solid×1；次要 = outline/ghost；危险勿与主 CTA 并列抢视觉 |
| 组件 | 复用 layout 登记的 PageHeader / TitleCard；禁止页内手写第二套 |

**非问题**：全站 `flush` 且标杆页头无卡、无右按钮 → 不强迫加标题卡。

## 菜谱 B · 行操作约定（硬规则）

列表/表格**最后一列操作**统一：

| 规则 | 要求 |
|------|------|
| 样式 | **幽灵按钮**（ghost）：无实心底、hover 浅底；图标优先，文案宜短 |
| 数量 | **≤4** 个可平铺；**>4** 时：保留 ≤3～4 个最高频，其余收入 **`…` 按钮 → DropdownMenu** |
| 删除 | 平铺或菜单内均为 **红色 destructive**；点击后 **AlertDialog** 确认 |
| 溢出菜单 | 触发器也是 ghost 的 `…`；危险项靠菜单底部并用红色 |
| 对齐 | 用本仓 `Button` ghost + `DropdownMenu`（或等价）；禁止每页手写一套实心蓝钮 |

扫描时：打开操作列，数按钮、看 variant、看删除色；窄屏下操作列被裁切且无 `…` → 一并记 P1。

## 语义色抽检（各菜谱）

| 检查点 | 通过标准 |
|--------|----------|
| 页头/KPI/入口图标 | 非全站同一蓝；按语义或域区分（走 Token） |
| 任务/作业/工单等**状态** | 不同状态不同色（Badge/点 + 文案）；禁止「全蓝 Badge」 |
| 主 CTA | 放**页头/标题卡右侧**（solid×1）；可用品牌主色；**勿**用行内实心钮代替页头主入口 |
| 删除/危险 | destructive 红 + 确认 |

## CRUD 承载选型（改造前填）

| 操作 | 字段量/风险 | 推荐 |
|------|-------------|------|
| 创建/编辑 | ≤5 简单字段 | Dialog 或 Sheet |
| 创建/编辑 | ≥8 或多步 | 独立页或 Wizard |
| 高级筛选 | 多条件 | Sheet / 可折叠工具栏；勿超大居中 Dialog |
| 删除/不可逆 | 任意 | AlertDialog；写清影响范围；触发控件为 **红色 destructive** |
| 列表行内操作 | 任意 | **ghost**；>4 → `…` 菜单 |
| 批量 | 任意 | 明确选中态 + 二次确认 |

同域选型写入报告「CRUD 约定」，修复时不得无故混用。

## 共享面（大仓 W1）

扫描若发现 ≥3 页复制粘贴的 Header/列表壳/空态 → **P1 应复用未复用**（或 P2 建议抽取），先抽共享单元再铺页：

- 色调 KPI / 快捷入口卡  
- 标准列表壳（Header + 工具栏 + 表 + Pagination）  
- 空态模板（图标 + 说明 + 主/次 CTA）  
- 页头 / 表单壳 / Query 空错态  

**禁止**：每页私有 shadow/gap/Badge 配方；禁止「只改观感、不抽组件」。

判定门槛、非问题、subagent 回传格式 → [component-reuse.md](component-reuse.md)。

## 分类输出格式

```markdown
| 路径 | 文件 | 菜谱 | 标杆参照 | 备注 |
|------|------|------|----------|------|
| /orders | pages/Orders.tsx | B | pages/AssetsList.tsx | |
| /orders/:id | pages/OrderDetail.tsx | E | pages/FormPageShell.tsx | |
| /projects/:id/tabs | … | C | … | 锁定作用域铬 |
```

改造方案如何写（菜谱 + 对标 + 区块 + 复用）→ [remediation-plan.md](remediation-plan.md)。
