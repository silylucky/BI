# Remediation Plan（改造方案）

简陋页 / 风格严重漂移 / 应复用未复用 等 **P0·P1（视觉·完整度·复用·壳）** finding，报告里不能只写「对齐一下」——必须附 **改造方案**。方案是**对齐本仓**的施工说明，不是另起视觉语言。

## 何时必写

| 情况 | 改造方案 |
|------|----------|
| 页级简陋、套卡、空态残缺、密度崩、半成品壳 | **必写**（可多 finding 共用一份「页级方案」） |
| 页头形态漂移 / 缺标题卡右操作 / flush 硬套卡 | **必写**（对标 `layout.md` + 标杆页头：左身份右操作） |
| 同构未复用 | **必写**（侧重抽壳 + 改引用；可挂在复用摘要下） |
| 空侧栏 / 菜单 404 / 提交无反馈 | **必写**短方案（壳或交互，不必整页区块树） |
| 行操作非幽灵 / >4 未收起 / 删除非红 / 状态·图标全蓝 | **必写**（可挂在列表壳 RP 下；写明 ghost + `…` + destructive + 状态分色） |
| 文案：字段名/甲方乙方/工程黑话上屏 | **必写**短方案（改 craft §8 用户向人话） |
| 纯文案润色 P2、书面延期 API | 一行修法即可，**不必**整块方案 |

同页多条 finding → **合并为一份**「页级改造方案」，finding 表里链到方案 ID（如 `RP-help-home`）。

## 方案从哪来（禁止空想）

按顺序取证，写进方案「依据」：

1. **菜谱**（A–F）— 本页属于哪类壳  
2. **锁定标杆页** path — 抄结构与密度，不抄业务文案  
3. **已有共享组件** — 能 import 则列为「复用」；不能则「建议抽取」（进 S0）  
4. **仓内 page-craft / design-system skill** — 有则叠加，无则跳过  
5. **反模式修法** — 本页命中的条目对应改法  

**禁止**：引入本仓没有的 UI 库；发明无 API 的假 KPI；改 RBAC/路由体系当「设计方案」。

## 模板（报告内粘贴）

```markdown
### RP-{短 id} · 改造方案 · {路径或同构组}

| 项 | 内容 |
|----|------|
| 目标页 | `path`（或多页列表） |
| 菜谱 | A–F / 扩展名 |
| 对标 | `标杆文件 path`（只读） |
| 依据 | 菜谱 + 标杆 + 共享壳…（各一句） |

**区块结构（自上而下）**

1. …（如：TitleCard/PageHeader：左 icon+标题+说明 · 右主CTA solid + 次要 outline/ghost）
2. …
3. …

**复用 / 抽取**

| 表面 | 动作 | 组件或建议名 |
|------|------|----------------|
| 页头 | import / 抽取 | `…`（形态 title-card\|flush；右操作：是/否） |
| 行操作列 | 统一 ghost | `Button variant="ghost"` + `…` Dropdown |
| 空态 | import / 抽取 | `…` |

**CRUD 承载**（若有）：短表 Dialog · 长表 独立页 · 危险 AlertDialog（触发控件 **红色 destructive**）
**行操作**（菜谱 B）：ghost 幽灵钮 · ≤4 平铺 · >4 → `…` Dropdown · 删除红
**语义色**（若 finding 含全蓝/状态无分色）：页头·KPI 图标分色 · 状态 Badge/点分色 · 走本仓 Token
**弹层遮罩**（若 finding 含遮罩过深）：共享 Overlay 调至约 **20%–30%** 黑（Sheet 优先 `/20`）；禁止业务页各自加 `/50` 及以上

**交互回声**：提交 pending · toast/就地错误 · 空态 CTA …

**不做**

- 不改路由/RBAC 模型
- 不引入新 UI 库
- 无契约不造假 KPI
- …

**验收**：对照反模式清零；与标杆同菜谱目视密度接近；共享壳已引用（或 S0 已建）。
```

## 长度

- 单页：区块 4～8 条；表格从简。  
- 同构一组：一份方案 + 页列表，避免五份复制。  
- 确认修复时 Phase 5 **按方案施工**；若实现偏离方案，须在完成摘要说明。
