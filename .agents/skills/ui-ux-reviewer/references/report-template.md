## 语气

- 短句；先危害再位置。  
- 改造方案写「对标哪页、复用啥、区块顺序、不做啥」，禁止空泛「优化 UI」。  
- 毕业结论诚实：未勾选完或有 Blind spot → 不可毕业。  
- 用户规则要求简体中文时用中文报告。
