## 路由勾选

1. 从路由表提取 path + 懒加载/组件名。  
2. 对照侧栏/菜单：有菜单无路由、有路由无菜单 → 记 P1（入口漂移）。  
3. 排除：login/callback、redirect-only、dev playground（若用户确认非产品）。  
4. 勾选表状态机：`待扫` → `通过` | `fail` | `延期`。

PR/变更面模式：主根 = diff 目录；仍须列出**受影响路由**全集，并对同菜谱邻页抽 1 个对照，防只修一页风格更碎。

```text

路由子集：{路径列表}

【对照真源 · 必须原文粘贴，不要让 lane 自己去读或去猜】
docs/ui/anchor.md 全文：{…}（无则写「缺设计锚」+ Phase 0.5 结论）
docs/ui/layout.md 全文：{…}（壳层、模板索引、禁止项一条不落）
本 lane 相关 *-ia.md 全文：{…}（含页菜谱对照与标杆路径）
基准可信度：{可信 / 部分不可信 / 不可信} · assumed 项：{…}
  → assumed 项只能用来写「与当前假设一致，假设待确认」，**禁止**据此判合规

锁定标杆（只读对照）：{paths}
已有共享壳：{FE Card 清单}
验收六维：视觉 / CRUD / 完整度 / 文案·Token / 组件复用 / 壳·导航·交互
反模式：见 anti-patterns + shell-interaction（含：内容区套卡、**列表外卡套表格内框**、页头形态漂移、页头缺右操作、甲方等合同口吻、行操作非幽灵）
页头：跟 layout.md 形态 title-card|flush|minimal；title-card 则左身份右操作（标杆有按钮则本页须有右槽）
列表行操作（菜谱 B）：ghost 幽灵钮；操作 >4 收起为 `…` Dropdown；删除红色 destructive + 确认
语义色：页头/KPI/入口图标勿全蓝；状态 Badge/点须分色；主 CTA 在页头用 primary solid
文案：用户向人话；禁字段名/查询参数名/甲方乙方/工程黑话上屏
复用：同菜谱页是否 import 共享壳；平行手写 → P1（证据列 ≥2 path + 应对齐的组件）
壳/交互：空侧栏、菜单↔路由、提交 loading/防连点、权限假可点；按 FE Card 做响应式/主题抽检
改造方案：简陋页/复用/壳类 P0·P1 必须按 remediation-plan.md 产出 RP 块（菜谱+对标+区块+复用+不做）；同页合并一份
置信度：P0 必须写触发场景；构不出则降级。
穷尽盘点：本 lane 路由子集里**每个** fail 都要列出（禁止 Top N / 代表页）；同构问题可并条但须完整 path 表，禁止「等 N 页」。回传 `routes_in_lane=N fail_listed=N`（fail_listed 须覆盖全部 fail）。

【密度下限（硬约束 · 每页）】
- 每页 finding 数（P0/P1/P2 + 「已通过项」）≥ 3；不足 3 时**必须**在回传末尾加 EXHAUSTED 段：
  - 实际查过的反模式关键词清单（按 AP-A~F 分类列）
  - 查看过的组件 path 清单
  - 抽样截图数 + 主观信心（high/medium/low）
- 禁止「扫两眼就交差」；禁止把通过项不当结果只报问题
- 无 EXHAUSTED 段且结果 < 3 → 该页视为未扫透 → Blind spot

【反模式独立计数器（硬约束）】
每页对六类反模式**各自独立**打 0/1/N（禁止合并成「反模式 N 条」）：
- AP-A 内容区套卡：0 | 1（含「列表外卡+表格内框」单独记一行证据）
- AP-B 行操作：0 | N（非幽灵数 / >4 未收起数 / 删除非红数 各列）
- AP-C 页头形态漂移：0 | 1（title-card/flush/minimal 不一致 / 标杆有右操作页头却空）
- AP-D 图标·状态全蓝：0 | N（页头图标 / KPI 图标 / 入口图标 / 状态 Badge）
- AP-E 文案：0 | N（字段名 / 甲方乙方 / PRD·ADR 编号 / 工程黑话 各计数）
- AP-F 遮罩过深：0 | 1（Dialog/Sheet/抽屉遮罩 >30% 黑）
命中即出**独立 finding**（不合并、不吞），finding 的 `ap_class` 字段填对应类。

回传：
```

## 复用审计 Subagent（可与域扫并行）

```text
你是只读「组件复用」审计 agent。不要改代码。
项目根：{ROOT}
FE Card 共享壳清单：{…}
菜谱分组与页面文件：{来自勾选表}
按 component-reuse.md 判定门槛回传「复用审计」块。
禁止把不同菜谱的正当差异报成未复用。

```

## 并行与波次

规模分档：<15 路由主 agent 串行（仍填勾选表）；中型按域 2～4 个 explore 并行；大型（50+）按 SKILL.md Phase 5 的 W1–W4 波次。  
共享组件文件锁：W2+ 禁止多代理同时改同一共享 path；共享变更单独批次。

## 与契约 / 后端

- 发现页要字段但 API 无：P1「缺契约」；允许**延期**并写进报告附录。  
- **禁止**用 mock 列表/假 KPI 混过毕业。  
- 若仓有 codegen（如 openapi、goctl、orval）：修 API 时遵守仓内文档；禁止手改标明的生成文件。

## 修复批次（确认后）

| 批次 | 内容 |
|------|------|
| S0 共享壳 | Header/列表壳/空态/Token；**含应复用未复用的抽取与改引用**；串行 |
| S1…Sn 分域 | 按勾选 fail 页；一域一代理或一菜谱一代理；须 import S0 结果 |
| API | 仅用户确认的契约项；跟本仓纪律 |
| 回归 | 反模式 rg + 同菜谱抽检 ≥2 页 + 标杆目视/截图 + 相关单测 |

完成定义：该批路径反模式清零或改「延期」；同构页已复用共享壳；**实现与已确认 RP 改造方案一致**（偏离须说明）；标杆无回归；勾选表更新。
