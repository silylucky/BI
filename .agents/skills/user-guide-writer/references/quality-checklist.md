# 交稿前质量清单

每篇写完或改完必须勾选。任一项否 → 不得交付。

## 读者与目标

- [ ] 有明确读者；步骤与权限匹配
- [ ] 标题是任务/概念目标，不是模块代号
- [ ] 开篇 1～2 句能回答「这篇让我干什么 / 懂什么」
- [ ] 文型正确（概念未伪装成逐步操作；登录文未要求已登录）

## 可执行性

- [ ] 步骤中的菜单/按钮文案已与 UI 核对，或标明 `待核对`
- [ ] 无「以 UI 为准」「或对应入口」等搪塞
- [ ] 一步一动作；关键步有「你会看到…」
- [ ] 成功标准用户可观察（非仅内部 URL/Cookie）

## 反复读

- [ ] 前置条件非万能套话
- [ ] 排障非与邻篇可互换的 401/403 三段
- [ ] 与同目录其他篇对照：不是换标题的同文

## 表达与导航

- [ ] 术语有人话解释（若是首次）
- [ ] 相关链接文字为可读中文标题
- [ ] 无新手文里的 Cookie/HttpOnly/内部实现主线
- [ ] 删掉了空壳章节（无内容的「常见失败」等）

## 批量任务额外

- [ ] 已有共享篇（登录/权限/找不到菜单）并被链接
- [ ] 文型矩阵已更新
- [ ] 抽检 ≥20% 篇通过本清单
