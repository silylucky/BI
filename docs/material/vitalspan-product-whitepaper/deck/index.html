定位与价值
定位句

平台定位与能力边界

VitalSpan 是面向政企与行业客户的自研可配置 BI 分析平台，对标 DataEase / Superset 核心能力，坚持零第三方 BI 运行时依赖。

In Scope（平台负责）

  • 多类别数据源接入与查询执行
  • 仪表板、主题分析、报表与即席查询
  • 可配置 RBAC 与行级权限
  • 数据同步与轻量清洗入托管库
  • 查询服务治理与总线对接
  • Web 门户与嵌入展现、开放只读 API

Out of Scope（平台不做）

  • 预置行业场景包自动加载
  • 嵌入 Superset/DataEase 作为生产组件
  • AI 智能问数（非当期对标项）
  • 一至三期 Dataset 语义层（四期交付）

核心亮点

本章展开 VitalSpan 的五大价值主张，说明用户多得到什么，以及平台如何支撑。

核心亮点
亮点总览

五大价值主张一览

  1. 1自研可控 — 生产环境无第三方 BI 运行时绑定，满足政企交付与长期演进
  2. 2多源统一 — 关系型、OLAP、时序、文档、搜索、API、文件等插件接入
  3. 3全链路展现 — 从接入、查询到仪表板、报表、嵌入的完整闭环
  4. 4可配置安全 — RBAC 菜单、行级权限、默认视图与用户覆盖
  5. 5治理差异化 — 查询服务申请、审批、发布与数据交换总线对接
核心亮点
深挖

亮点一：自研可控

场景：行业客户需在信创或内网环境长期运维 BI 能力，不能接受 GPL 绑定或厂商黑盒升级。

能力：BI 展现、查询、连接、权限、治理全栈自研；对标 DataEase/Superset 走查设计，不部署其运行时。

结果：交付清单可验证「无 Superset/DataEase 容器或进程」；版本演进由实施团队自主掌控。

核心亮点
深挖

亮点二：多源统一接入

场景：同一企业并存 MySQL 业务库、时序监控、文档检索与 Excel 报送文件。

能力：连接器注册表按类型插件扩展；关系型走 SQL，时序/文档/搜索走原生查询；可选同步入托管分析库并配置轻量清洗规则。

结果：数据工程师在一个控制台完成建源、同步与出数验证，无需为每类源单独搭工具链。

核心亮点
深挖

亮点三：完整 BI 展现

场景：管理层需要驾驶舱，分析员需要自助探索，外部门户需要嵌入只读图表。

能力：仪表板栅格与像素布局、主题分析、报表模板与调度、图表类型目录、iframe/SDK 嵌入面。

结果：建设与消费在同一应用内由权限区分；对外分享不暴露完整管理壳层。

核心亮点
价值闭环

从数据到决策的价值闭环

接入 → 治理 → 分析 → 展现 → 共享

  • 接入：外部源注册、凭证托管、连通性验证
  • 治理：权限策略、语义数据集、服务审批
  • 分析：SQL/原生查询、图表配置、主题钻取
  • 展现：仪表板、报表、嵌入门户
  • 共享：开放 API、总线注册、受控发布

平台帮助组织把「数据散落各处」变为「可授权、可审计、可复用的分析资产」。

技术架构
架构总览

系统组成与信任边界

控制台 — 单 Web 应用，管理员与分析员按权限看到不同菜单

API 服务 — 统一业务入口，承载数据源、查询、仪表板、治理

平台数据层 — 元数据、权限、仪表板定义、审计与作业状态

托管分析库 — 可选，承接同步后的分析用数据副本

外部系统 — 业务数据源、企业身份源、数据交换总线

信任边界：写操作经身份校验与权限裁决；凭证加密存储。

技术架构
同步主路径

业务请求如何被安全处理

  1. 1用户发起操作 — 在控制台或嵌入页触发查询或管理动作
  2. 2身份与权限校验 — 确认会话有效，裁决菜单与数据范围
  3. 3业务执行 — 路由到对应能力域执行查询或写配置
  4. 4统一响应 — 成功返回结果；失败返回可理解提示
  5. 5审计留痕 — 关键管理操作记入审计日志
技术架构
扩展路径

异步同步与开放集成

数据同步：配置作业 → 执行同步 → 写入托管库 → 注册为可查询源

开放集成：嵌入 SDK 输出只读图表；开放 API 提供只读查询；发布后注册至数据交换总线

业务场景
场景 A

场景 A：多源接入总览

背景：需将业务库、时序与 Excel 周报纳入同一分析门户。

阶段：发现源 → 注册连接 → 可选同步 → 验证出数 → 搭建仪表板 → 授权消费

成功标准：分析员仅看到授权仪表板，数据与源端一致。

业务场景
步骤详解

场景 A：配置与同步步骤

  1. 1选择连接器 — 按源类型选择对应模板
  2. 2填写连接信息 — 配置地址与库表范围
  3. 3连通性验证 — 确认网络与账号可用
  4. 4创建同步作业 — 将表同步入托管库
  5. 5配置清洗规则 — 字段映射与轻量转换
  6. 6查看执行历史 — 核对同步状态与行数
业务场景
步骤详解

场景 A：仪表板消费与授权

  1. 1创建仪表板 — 选择布局，添加图表
  2. 2绑定查询 — 直连数据源执行查询
  3. 3配置筛选联动 — 全局筛选驱动多图
  4. 4预览发布 — 验证后切换消费态
  5. 5角色授权 — 配置可见角色范围
  6. 6嵌入分享 — 生成外部门户链接
