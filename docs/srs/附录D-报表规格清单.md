# 附录 D：报表需求参考实例

> **版本**：V1.2（仅文档参考）  
> **定位**：户户通项目报表需求的**参考清单**；管理员在 M6 中**手工配置**，平台不预装、不导入  
> **父文档**：[附录 S 户户通需求参考](附录S-参考场景户户通.md)  
> **平台关联**：平台 FR-6.3/6.4 描述报表配置能力；本附录为户户通实施对照表  
> **自研模块**：M6 报表子系统  
> **口径状态**：`已确认` / `待业务确认`  
> **工作坊**：WS-S-01 场景报表包口径确认（一期末，场景可选；见 [SRS §8.6](全生命周期系统需求规格说明书.md#86-工作坊排期)）
