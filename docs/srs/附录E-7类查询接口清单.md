# 附录 E：查询接口分类能力模板

> **版本**：V1.1（能力模板 + 场景实例）  
> **定位**：平台 **可配置多类查询接口** 的分类能力模板；下表七分法为建议结构，正式 taxonomy 由 WS-01 确认  
> **关联需求**：平台 FR-1.1 查询服务接口与数据交换总线对接  
> **场景实例**：[附录 S §9](附录S-参考场景户户通.md)（**文档参考**，非自动加载）· 下文 `【参考实例】` 为户户通 API 命名示例  
> **自研模块**：M3 查询分析引擎、M8 查询服务治理  
> **状态**：`[待确认]` 类名与边界需与数据交换总线规范对齐

## 一、分类总览

| 类别编号 | 类名（建议） | 描述 | 典型消费者 | 状态 |
|----------|--------------|------|------------|------|
| **CAT-01** | 实体生命周期查询类 | 可配置实体类型之状态与关系查询 | 门户、业务系统 | 待确认 |
| **CAT-02** | 统计分析聚合类 | 按地域/时间/分类维度的聚合统计 | 驾驶舱、报表 | 待确认 |
| **CAT-03** | 地域维度查询类 | 服务区域、GIS 分布、地域下钻 | 驾驶舱、主题分析 | 待确认 |
| **CAT-04** | 时间序列分析类 | 日/周/月/同比环比时序数据 | 主题分析、报表 | 待确认 |
| **CAT-05** | 工单与业务受理类 | 工单类业务统计与明细 | 报表、监管 | 待确认 |
| **CAT-06** | 生产与销售统计类 | 厂商/型号等生产销售统计 | 报表、企业门户 | 待确认 |
| **CAT-07** | 组织行为审计类 | 操作主体登录、行为、层级查询 | 驾驶舱、审计 | 待确认 |

> **说明**：上表为平台 **建议七分法**能力模板。户户通场景将 CAT 描述实例化为工号/机顶盒等实体，见附录 S §9。正式类名、合并/拆分由 WS-01 与总线 taxonomy 对齐。

## 二、各类接口规格模板

### CAT-01 实体生命周期查询类

| 项目 | 内容 |
|------|------|
| **示例 API** | `GET /api/v1/entities/{entityType}/{entityId}` |
| **入参** | `entityType`、`entityId`、可选扩展属性；【场景示例】`user/stb/card/workno/store`、`chipId`、`hsmId`、`mobile`（附录 S） |
| **出参** | 实体详情、生命周期当前状态、关联实体列表 |
| **权限** | M7：地域 + 实体生命周期维度 + 物理表 |
| **总线注册** | OpenAPI 3.0；查询类只读 |

### CAT-02 统计分析聚合类

| 项目 | 内容 |
|------|------|
| **示例 API** | `GET /api/v1/stats/aggregate` |
| **入参** | `metric`、`groupBy`（province/city/locType/userType）、`startDate`、`endDate` |
| **出参** | 聚合结果集 `{ dimensions[], values[] }` |
| **权限** | M7：地域、时间范围组 |
| **PoC 对应** | 【场景示例】`/api/dashboard/user-distribution`、`user-growth-heatmap`（附录 S §9） |

### CAT-03 地域维度查询类

| 项目 | 内容 |
|------|------|
| **示例 API** | `GET /api/v1/geo/distribution` |
| **入参** | `level`（country/province/city/county/village）、`metric`、`locType` |
| **出参** | 行政区划编码 + 指标值，支持 GeoJSON 友好格式 |
| **权限** | M7：地域维度组（本级及下级） |

### CAT-04 时间序列分析类

| 项目 | 内容 |
|------|------|
| **示例 API** | `GET /api/v1/timeseries` |
| **入参** | `granularity`（day/week/month）、`compare`（yoy/mom）、`entityType` |
| **出参** | 时间序列点数组 |
| **权限** | M7：时间维度组 |

### CAT-05 工单与业务受理类

| 项目 | 内容 |
|------|------|
| **示例 API** | `GET /api/v1/tickets/stats` |
| **入参** | `ticketType`、`problemType`、`province`、`userType` |
| **出参** | 问题数量、占比、万户投诉率 |
| **权限** | M7：地域 + 物理对象（工单表） |

### CAT-06 生产与销售统计类

| 项目 | 内容 |
|------|------|
| **示例 API** | `GET /api/v1/production/stats` |
| **入参** | `vendorType`（enterprise/scheme/model/dcas）、`brandId`、`locType` |
| **出参** | 入库、库存、开户、开通分项 |
| **权限** | M7：企业用户仅本 `brandId` |

### CAT-07 权限与工号行为类

| 项目 | 内容 |
|------|------|
| **示例 API** | `GET /api/v1/workno/behavior` |
| **入参** | `worknoType`（all/province/retail/poverty）、`province`、`dateRange` |
| **出参** | 登录数、操作数、分布 |
| **权限** | M7：组织层级数据域；【场景示例】专营点本工号及子工号 |

## 三、总线对接要求（FR-1.1）

| 要求项 | 说明 |
|--------|------|
| 接口语法描述 | 发布工单须附带 OpenAPI YAML |
| 自动注册 | M8 发布引擎调用总线注册 API（端点 `[待总线规范确认]`） |
| 查询类型 | 只读 GET；复杂查询可用 POST + body |
| 版本策略 | `/api/v1/` 前缀；破坏性变更升 v2 |
