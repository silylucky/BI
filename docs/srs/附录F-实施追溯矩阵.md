## 二、NFR 分期门槛

| NFR | 类别 | 要求 | 验收期次 | 验收方法 |

| NFR-01 | 性能 | Dashboard 首屏 ≤ 5s | 一期 | 并发压测 |

| NFR-04 | 扩展性 | 新数据源/实体不改核心 | 四期 | 扩展演练 |
