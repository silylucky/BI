# 附录 S：户户通需求参考实例

> **版本**：V1.1（仅文档参考）  
> **定位**：广电户户通/村村通业务的**需求参考文档**。**不参与运行时加载**，平台不会自动注入数据集、Dashboard、角色或报表。  
> **关联平台规格**：[自研 BI 分析平台需求规格说明书.md](全生命周期系统需求规格说明书.md) V3.2

## S.1 概述

| 项目 | 内容 |
|------|------|
| **文档用途** | 记录户户通项目曾提出的业务需求，供实施时**人工对照**在平台中配置 |
| **业务背景** | 直播卫星户户通/村村通全生命周期数据管理与分析 |
| **覆盖实体** | 工号、用户、机顶盒、加密卡、专营点（五类） |
| **与平台关系** | 管理员自行：连接数据源 → **图表绑定 SQL/表** → 配角色 → 建 Dashboard/报表（**无需 Dataset 层**，四期可选升级） |

## S.2 源业务系统与数据流

### S.2.1 源系统清单

|------|--------|----------------------|


| 批次 | 期次 | 源系统 | 下游依赖 |
|------|------|--------|----------|

| S-DATA-B | 二期初 | 政企通、官方网站 | 个人用户 D-N20~N22、行业用户 D-N01~N02 |

- OGG 实时同步源端业务系统 → 全局大集中库

- **北斗扩展**：北斗定位型机顶盒设备、北斗用户清洗程序

## S.3 五类核心实体与生命周期

### S.3.1 实体属性摘要

| 实体 | 关键属性 | 生命周期 |
|------|----------|----------|
| 用户 | 开户类型、机顶盒类型（基站/北斗）、地域、开通状态 | 开户→安装→开通→使用→销户 |
| 机顶盒 | 生产商、主芯片方案商、安全芯片厂商、CHIPID、型号、类型 | 组件→生产→待开户→待安装→已安装→维修 |
| 加密卡 | HSMID、业务类型（基站/北斗） | 待入关→…→关停 |
| 工号 | 类型（整省/零售/扶贫/个人/社会化）、绑定手机号 | 申请→审批→下发→使用→挂起/注销 |
| 专营点 | 地域、状态 | 申报→审批→…→注销 |

### S.3.2 固定报表生命周期维度（FR-3.1 场景实例）

| 实体 | 状态维度 | 活动维度 |
|------|----------|----------|
| 机顶盒 | 组件、生产、待开户、待安装、已安装、维修（6） | 生产、入库、开户、安装开卡、损坏（5） |
| 加密卡 | 待入关、待入库、待销售、已出库、挂起、关停（6） | 入库、销售、出库、挂起、关停（5） |
| 专营点 | 申报、审批、复核、备案、运营、暂停服务、注销（7） | 入库、销售、出库、挂起、关停（5） |
| 工号 | 新建申请、新建待审批、新建下发、使用、变更申请、变更待审批、变更下发、挂起、注销（9） | 新建审批、新建下发、变更审批、变更下发、挂起、注销（6） |
| 用户 | 开户、待安装、已安装未开通、已开通、使用、销户（6） | 开户、安装、开通、销户（4） |

### S.3.3 主题分析配置（FR-4 场景实例）

| 分析域 | 时间维度 | 空间维度 |
|--------|----------|----------|
| 时间域 | 当前时刻、当月每天、当季每周、当年每周、某年每周同比环比 | — |
| 空间域 | — | GIS 全国分布 + 各生命周期节点数量统计 |

| 场景 FR | 实体 | 地域粒度 | GIS 要求 |
|---------|------|----------|----------|
| S-FR-4.1 | 机顶盒 | 全国/省/市 | 分布图 + 节点统计 |
| S-FR-4.2 | 加密卡 | 全国/省/市 | 同左 |
| S-FR-4.3 | 专营点 | 全国/省/市 | 同左 |
| S-FR-4.4 | 工号 | 全国/省/市 | 同左 |
| S-FR-4.5 | 用户 | 全国/省/市 | 同左 |

## S.6 驾驶舱配置参考（对应 FR-6.1）

若按本参考实施，建议 Dashboard 包含以下 5 个组件（各组件绑定数据源 SQL/表查询）：

| # | 组件 | 具体要求 |
|---|------|----------|
| 1 | 全国用户分布图 | 增加村村通开通用户数；地图显示各省户户通/村村通用户数 |
| 2 | 用户增长统计图 | 热力图显示各省当月户户通新增开通数 |
| 3 | 各省用户统计图 | 更新七普农户数；增加用户分类；显示省用户量占全国比例；省份降序排列 |
| 4 | 工号登录分布图 | 增加个人及社会化工号登录；地图顶部显示登录总数 |
| 5 | 里程碑事件 | 按发生时间倒序刷新 |

**实施参考**：管理员配置完成后可做冒烟验收，非平台出厂能力。

## S.7 实体总览优化（S-FR-6.2）

| 子模块 | 关键变更 |
|--------|----------|
| 用户统计 | 「用户开通数统计」→「用户统计」；全部/基站/北斗；个人用户地域分布；TOP5 降序 |
| 用户详情 | 开户类型新增个人/社会化/省级企业工号；机顶盒类型筛选 |
| 机顶盒统计 | 全部/基站/北斗；生产商/主芯片方案商/安全芯片厂商；TOP3 市场占有率 |
| 机顶盒类型 | 基本型、教育定制型、融合型、增强型 |
| 工号统计 | 户户通全部工号；按工号类型联动 |
| 实体查询 | CHIPID、HSMID、手机号查询；实体关系与生命周期关联展示 |
| 服务区域分析 | 市/县/乡/村四级；服务区域数及全国占比 |
| 数据总体分析 | 饼图集团/个人/社会化；曲线多维度标签 |
| 加密卡分析 | 北斗型时模块名改为「终端芯片统计」 |
| 工号行为分布 | 全部/整省/零售/扶贫；总数与驾驶舱一致 |

**分期（场景验收）**：

| 批次 | 期次 | 子模块 | 验收 |
|------|------|--------|------|
| S-FR-6.2-A | 二期初 | 用户/机顶盒/工号统计 | 与 S-FR-6.1 口径一致 |
| S-FR-6.2-B | 二期中 | 实体查询、服务区域 | 越权测试；四级下钻 |
| S-FR-6.2-C | 二期末 | 数据总体、加密卡/工号行为 | 工号行为总数=驾驶舱 |

## S.8 场景报表包

### S.8.1 报表调整（11 张，S-FR-6.3）

在既有报表中统一增加：业务类型（北斗定位）、用户类型（个人）、北斗定位用户总数/已开通数/未开通数/当日新增登记录入数、个人工号推进情况等。

涉及报表：整省零售扶贫用户总体/开通情况、设备类型用户情况、机顶盒厂商用户整体、集团用户总体/开通、用户开通日报、地市/区县/乡村用户情况、机顶盒企业/方案商/型号生产销售情况。

**明细规格**：[附录 D §一](附录D-报表规格清单.md)

### S.8.2 新增报表（22 张，S-FR-6.4）

| 分类 | 报表名称 | 核心指标 |
|------|----------|----------|
| 行业用户 | 行业用户总体/开通情况表 | 登记录入、开通、开通率 |
| 变更统计 | 整省零售扶贫变更情况统计表 | 状态变更、销户、净增长 |
| DCAS | DCAS 厂商生产销售情况表 | 入库、库存、各类型开户/开通 |
| 企业工号 | 省级工号开通情况表（4 张） | 开户、开通、比例、日指标 |
| 投诉分析 | 主要问题统计表（2 张） | 问题类型占比 |
| 受理分析 | 业务受理情况统计表（2 张） | 各省问题数量及占比 |
