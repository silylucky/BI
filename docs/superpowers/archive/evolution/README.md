# 演化轮次选题（G2）

由 **evolution-picker** 产出，文件名：

```
YYYY-MM-DD-round-target.md
```

## 最小结构（摘自 evolution-topic-picker）

```markdown
## 本轮演化目标（共 N 项）

### 选题决策
- 批量主题 / 来源 / 合并理由 / 范围框定

### 候选对比
| 候选 prd ID | 加权总分 | 未选原因 |

### 子项 1：<prd ID> <标题>
- 选题理由 / 验收标准 / 范围框定（文件与模块）
```

产出后同步 [`docs/automate/evolution-state.md`](../../automate/evolution-state.md)「当前轮次」字段。

本目录无文件时表示尚未启动演化轮次。
