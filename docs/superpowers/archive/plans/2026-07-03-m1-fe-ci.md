# M1 前端壳层与 CI 实现计划

> **执行模式：** subagent-driven-development (option 1)
> **范围框定：** `fe/`（Vite/pnpm 脚手架、Tailwind Token、Admin 壳层、`check:design`）、`tests/`、`.github/workflows/ci.yml`、`.gitignore`（共约 26 文件；不含 `backend/pyproject.toml` 改动、不含 M1 文档回写）
> **子项：** BOOT-002（子项 1–3）、BOOT-006
> **项目技能：** `.agents/skills/`（P3 按 Task **Files** 与 **Skills** 按需 Read）
> **项目规则：** `.cursor/rules/`（`vitalspan-project.mdc`、`common.mdc`、`prd-sync.mdc` alwaysApply；`fe-ui.mdc` 触及 `fe/**`；`backend-fastapi.mdc` 触及 `tests/**/*.py`）
> **For agentic workers:** REQUIRED SUB-SKILL: `subagent-driven-development`（option 1，每 Task 独立 subagent + 任务间 review）

**Goal:** 落地 M1 前端 Admin 静态壳层（Vite + Tailwind v4 + shadcn 最小集 + 290px 侧栏）与 CI 质量门禁（ruff、pytest、`fe build`、`check:design`）。

**Architecture:** pnpm + Vite react-ts 承载 `fe/`；`index.css` 为唯一 Token 声明文件；壳层从 b-design-system skill 模板精简复制；`check-design.mjs` 扫描 `fe/src` 禁裸色；GitHub Actions 并行 `backend` + `frontend` jobs，不启 postgres。

**Tech Stack:** React 19、react-router v7、Tailwind CSS v4（`@tailwindcss/vite`）、shadcn/ui + Radix、lucide-react、pnpm 9、Python 3.11、ruff、pytest

## Global Constraints

- 零第三方 BI 运行时依赖（NFR-08）
- 前端根目录 **`fe/`**（禁止 `frontend/`）
- M1 仅 Admin **静态壳层**；不交付 TanStack Query、`@/lib/api.ts`、Portal/Embed 业务页
- `index.css` 为唯一允许裸 hex/rgb 的文件；业务文件禁硬编码色（`check:design` + `@design-token-ok` 行豁免）
- 侧栏 290px / 折叠 90px；内容区 `max-w-(--breakpoint-2xl)`（`layout.md` §2）
- API 前缀 `/api/v1/`；健康检查 `/health`（smoke 测试用）
- 单函数 ≤60 行；单 fe 业务文件 ≤300 行
- 本轮不写 PRD/API/services 文档回写（留 P5）
- CI **不启动** docker postgres
- `backend/pyproject.toml` 已含 ruff/pytest 配置，本轮不改

- [ ] **Step 1: 创建 `fe/scripts/check-design.mjs`**

```javascript
#!/usr/bin/env node
import fs from "node:fs";
import path from "node:path";
import { fileURLToPath } from "node:url";

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const SRC_ROOT = path.resolve(__dirname, "../src");
const SKIP_FILES = new Set([path.join(SRC_ROOT, "index.css")]);
const EXT_RE = /\.(ts|tsx|css)$/i;
const HEX_RE = /#[0-9a-fA-F]{3,8}\b/;
const RGB_RE = /rgba?\(/;

function walk(dir, files = []) {
  for (const entry of fs.readdirSync(dir, { withFileTypes: true })) {
    const full = path.join(dir, entry.name);
    if (entry.isDirectory()) {
      walk(full, files);
    } else if (EXT_RE.test(entry.name)) {
      files.push(full);
    }
  }
  return files;
}

function checkFile(filePath) {
  if (SKIP_FILES.has(filePath)) return [];
  const content = fs.readFileSync(filePath, "utf8");
  const lines = content.split("\n");
  const hits = [];
  for (let i = 0; i < lines.length; i += 1) {
    const line = lines[i];
    if (line.includes("@design-token-ok")) continue;
    const colHex = line.search(HEX_RE);
    if (colHex >= 0) {
      hits.push({ line: i + 1, col: colHex + 1, snippet: line.trim() });
      continue;
    }
    const colRgb = line.search(RGB_RE);
    if (colRgb >= 0) {
      hits.push({ line: i + 1, col: colRgb + 1, snippet: line.trim() });
    }
  }
  return hits;
}

const files = walk(SRC_ROOT);
let failed = false;

for (const file of files) {
  const hits = checkFile(file);
  for (const hit of hits) {
    failed = true;
    const rel = path.relative(process.cwd(), file);
    console.error(`${rel}:${hit.line}:${hit.col} hardcoded color — ${hit.snippet}`);
  }
}

if (failed) {
  process.exit(1);
}

console.log(`check:design passed (${files.length} files scanned)`);
process.exit(0);
```
