# 设计规格（P1）

由 **evolution-designer** 产出（叠加 Superpowers `brainstorming`），文件名：

```
YYYY-MM-DD-<name>-design.md
```

输入：[`../evolution/`](../evolution/) 中当轮 `round-target.md` + 范围框定内代码。

与 SRS/PRD 关系：

- 不新增产品需求；设计须可追溯到 `docs/automate/prd/` 功能 ID
- 架构决策冲突时以 [`docs/arch.md`](../../arch.md) 为准

本目录无文件时表示当前无活跃设计稿。
