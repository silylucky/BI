# 报表中心使用指南

> **读者**：业务分析师、报表查看者（`report:read`）；IT 管理员（另含 `report:manage`）  
> **最近更新**：2026-07-31  
> **相关 PRD**：[F08-RPT](../automate/prd/F08-RPT.md) · **壳层 IA**：[layout.md](../ui/layout.md)

---

## 报表中心能做什么

| 能力 | 说明 | 谁可以用 |
|------|------|----------|
| **全部报表（Hub）** | 浏览授权模板、快捷入口、角色默认报表、预制分析预览 | admin / analyst / viewer |
| **预制分析报表** | 运行系统预置的分析（表格结果） | admin / analyst / viewer（运行权限受绑定配置约束） |
| **打开并运行模板** | 对 Word / Excel / PDF 模板发起 Web 运行并查看结果 | admin / analyst / viewer |
| **报表导出** | 将当前模板导出为 PDF / Word / Excel | 浏览页自动绑定模板；管理员可在模板详情导出 |
| **报表模板** | 目录树、模板块、扩展指标、预览、调度、批量导入 | 仅 `report:manage`（通常 admin） |
| **报表调度** | 定时任务列表（模板/看板/大屏）、接收人、执行历史、手动执行与失败重试 | 仅 `report:manage` |
| **看板定时报告** | 在看板/大屏编辑页「定时推送」创建 PDF 定时推送 | 仅 `report:manage` 或 `dashboard:schedule` |

> **说明**：「可视化模板」（看板/大屏）在侧栏 **可视化** 分组，与本文 **报表模板** 不是同一模块。

## 进入报表中心

1. 使用已分配角色的账号登录管理端（本地开发一般为 `http://localhost:5173/admin`）。
2. 在左侧导航找到 **报表** 分组，点击 **报表中心** 展开子菜单。
3. 子菜单项：
   - **全部报表** → Hub 首页（`/admin/reports/center`）
   - **预制报表** → 预制分析列表（`/admin/reports`）
   - **报表模板**、**报表调度** → 仅管理员可见

## 业务用户：从 Hub 找报表并查看

### 打开角色默认报表（若已配置）

1. 进入 **全部报表** 页。
2. 若管理员已为您的角色绑定默认模板，页顶会出现 **角色默认报表** 卡片（星标）。
3. 点击 **打开默认报表** → 进入浏览页并自动运行。

若卡片提示「默认模板暂未在目录中同步」，请联系管理员检查模板目录与角色绑定。

### 浏览授权报表模板

1. 在 **授权报表模板** 区域：
   - 使用搜索框按 **报表名称** 筛选；
   - 使用 **全部 / PDF / Word / Excel** 切换格式。
2. 在卡片上点击 **打开并运行**。
3. 浏览页会 **自动运行一次** 报表；也可点击 **运行报表** 重新执行。
4. 在 **运行结果** 卡片中查看表格数据。
   - 若显示「暂无业务数据，当前为示例展示…」，表示模板尚未配置完整业务数据，请联系管理员。
5. 需要文件时：在页底 **报表导出** 区选择格式，点击 **发起导出**；完成后点 **下载**。
6. 点击页头 **返回全部报表** 回到 Hub。

### 运行预制分析

**方式 A：从 Hub 快捷进入**

1. 在 **预制分析** 区块找到目标项，点击 **运行**；或点击 **进入预制报表** 进入完整列表。
2. 若预制超过 6 条，可点 **展开全部 (N)** 在 Hub 内查看全部预览。

**方式 B：预制报表页**

1. 侧栏 **报表中心 → 预制报表**。
2. 在列表工具栏搜索名称或分析类型；表格列：**报表名称 / 分析类型 / 实体类型 / 操作**。
3. 点击某一行的 **运行**（仅当前行显示「运行中…」，其他行仍可操作）。
4. 下方 **运行结果** 出现表格即表示成功。
5. 点击 **返回全部报表** 回 Hub。

**无权运行时**：出现「无权运行预制报表」说明当前角色不在该绑定的允许范围内，请联系管理员。

## 管理员：维护模板与调度

### 管理报表模板目录

1. 侧栏 **报表中心 → 报表模板**。
2. 左侧目录树选择文件夹或模板；可 **新建文件夹** / **新建模板**。
3. 选中模板后，右侧 Tabs：
   - **基本信息**：格式、模板键、导出；
   - **模板块**：编辑 Word/Excel/PDF 块结构；
   - **扩展配置**：增减指标与筛选器（保存需填写 **变更说明**）；
   - **预览**：查看扩展渲染效果；
   - **调度**：为本模板创建定时任务（日/周/月向导、接收人、时区）；
   - **批量导入**：批量新增报表节点。

### 管理报表调度

1. 侧栏 **报表中心 → 报表调度**。
2. 使用 Tab **全部 / 模板 / 看板/大屏** 筛选任务来源；工具栏可 **搜索** 调度源、接收人或频率。
3. 列表查看：**源类型 / 调度源 / 频率 / 接收人 / 附件 / 状态 / 操作**（状态已中文化）。
4. 点击调度源名称展开 **执行历史**；失败记录可 **重试**。
5. 新建方式：
   - **模板调度**：**报表模板** 详情 → **调度** Tab；或列表页 **在模板中新建**。
   - **看板定时报告**：打开看板/大屏 **编辑页** → 工具栏 **定时推送**；或报表中心 Hub **从看板/大屏创建** 快捷入口。

### 看板定时报告（管理员）

1. 打开目标看板或大屏 → 进入 **编辑页**。
2. 点击工具栏 **定时推送**，配置：
   - **频率**（每天/每周/每月 + 执行时间）；
   - **接收人**（可添加角色、系统用户、外部邮箱）；
   - **附件格式**（PDF）；
   - **时区**。
3. 点击 **创建定时报告**，再 **激活**；可选 **立即试发** 验证。
4. 在 **报表调度 → 看板/大屏** Tab 统一管理。

> **产物说明（2026-08-03）**：看板/大屏定时 PDF 附件为 **可视化快照**（Playwright 截取画布 PDF）；执行历史标注「可视化快照」。历史「布局摘要」记录为升级前产物。Excel/CSV 导出仍为组件布局清单。

**本地可视化 PDF 闭环前置（开发）**

1. 仅保留**一个**前端 dev：`cd fe && pnpm dev --host 127.0.0.1 --port 5173`（避免 `localhost:5173` 上旧 Vite 子路径实例干扰 Playwright）。
2. 后端 `backend/.env`：`FE_BASE_URL=http://127.0.0.1:5173`，`FE_BASE_PATH` 留空；重启 uvicorn。
3. `docker compose up -d mailhog`（SMTP `1025`，Web UI `http://localhost:8025`）。
4. `pip install playwright && playwright install chromium`。

### 维护预制绑定（管理员）

1. 侧栏 **报表中心 → 预制分析**。
2. 列表非空时，点击 **新建预制绑定**（或侧栏 **新建**）填写绑定键、显示名、实体类型与分析类型后 **创建绑定**。
3. 选中已有项 → **绑定配置** Tab 可修改显示名、实体、分析类型与维度，或 **删除绑定**。
4. **运行结果** Tab 运行后可 **导出当前结果**（PDF / Word / Excel）。
5. 实体类型须在元数据中已注册物理表；开发演示可设 `DEV_REPORT_SEED=1` 写入 `equipment` 样例表。

> 绑定键创建后不可修改。内置演示绑定（如 `prefab-entity-lifecycle`）在开发环境重启后可能由种子重新写入。

## 常见问题

| 现象 | 可能原因 | 建议 |
|------|----------|------|
| 定时报告执行失败「SMTP 未配置」 | `RPT_SMTP_*` 未设置或 MailHog 未启动 | 本地开发：`RPT_SMTP_HOST=localhost`、`RPT_SMTP_PORT=1025` 并启动 MailHog；见 `backend/.env.example` |
| PDF 导出失败「Playwright 未安装」 | 后端缺少 Chromium | `pip install playwright && playwright install chromium`；`FE_BASE_URL=http://127.0.0.1:5173` 且前端 dev 已启动 |
| PDF 导出 502 / selector 超时 | Playwright 打不开 export 页 | 确认单实例 Vite；勿用 `localhost` 若另有 `/sc-datav/` 进程占用 5173 |
| 预制报表无法运行 | `DEV_REPORT_SEED=0` 且无实体物理表 | 开发环境设 `DEV_REPORT_SEED=1` 并重启后端 |
| 侧栏没有「报表模板/调度」 | 账号仅有 `report:read` | 联系管理员分配 `report:manage` 或 admin 角色 |
| 预制运行提示无权 | 绑定 `allowedRoles` 未包含当前角色 | 管理员调整预制绑定或用户角色 |
| 浏览页只有示例数据 | 模板扩展/数据源未配置 | 管理员在 **扩展配置** Tab 完善 |
| 导出无下载链接 | 导出任务失败或仍在处理 | 查看导出区 **状态**；仍失败联系管理员 |
| Hub 搜不到模板 | 名称不匹配或格式筛选过窄 | 清空搜索、选 **全部** 格式 |
