# VitalSpan 30 分钟内部演示手册

> **适合**：公司内部产品评审、研发验收和售前演练  
> **演示环境**：VitalSpan staging（内网）  
> **演示方式**：以既有数据为主，全程只读，不创建、删除、运行同步或发送邮件  
> **预计时长**：30 分钟

本手册帮助主讲人用一条完整主线说明 VitalSpan 如何完成“接入数据 → 同步清洗 → 组织数据 → 生成看板/大屏 → 输出报表”。演示结束时，听众应能说清 VitalSpan 的产品定位、核心能力和当前交付边界。

## 先记住三句话

1. VitalSpan 是面向政企和行业数据团队的**自研 BI 平台**，生产运行不依赖 DataEase 或 Superset。
2. 图表与报表出数统一经 **Dataset**；同步任务可将数据清洗后写入托管分析库。
3. 仪表板服务日常分析，数据大屏服务固定分辨率投放，报表中心承接定时 PDF 和固定版式输出。

## 演示边界

本次采用只读主路径。以下动作不在现场执行：

- 不点击 **新建数据源**、**新建任务**、**新建 Dataset**、**新建看板**或**新建大屏**。
- 不点击同步任务的 **手动运行同步**、**删除任务**或批量删除。
- 不修改 Dataset、看板、大屏、模板、角色或系统配置。
- 不创建定时报告，不执行邮件试发，不下载或展示包含敏感数据的产物。
- 不进入隐藏的治理导航作为客户主路径，也不演示尚需环境签收的外部总线闭环。

如果评审人要求现场修改数据，先说明：“当前 staging 按只读演示准备，写操作可在会后复制环境中单独验收。”

## 会前 15 分钟检查

### 1. 检查网络和服务

1. 确认演示电脑处于可访问 `192.168.10.0/24` 的内网。
2. 在浏览器打开健康检查：

   `http://192.168.10.22:8088/health`

3. 页面应显示：

   ```json
   {"status":"ok"}
   ```

4. 打开管理端：

   `http://192.168.10.22:8088/admin`

5. 你应进入 VitalSpan 登录页，并看到 **欢迎回来**、**用户名**、**密码**和 **登录**。

### 2. 检查登录

- 演示账号：`admin`
- 密码：从演示环境的 `VITALSPAN_DEV_ADMIN_PASSWORD` 或团队受控密钥台账获取。
- 不要把密码写进演示文档、聊天消息或投屏画面。
- 登录后若浏览器仍显示旧页面，先按 `Ctrl+F5` 强制刷新。

### 3. 检查演示数据

登录后依次快速确认：

- **数据准备 → 数据连接 → 连接管理** 中存在官方示例数据连接。
- **数据准备 → 数据连接 → 同步任务** 中存在可查看的任务和运行历史。
- **数据准备 → 数据集** 中能看到带 **官方示例** 标记的 Dataset。
- **分析 → 仪表板** 中存在 **官方示例 · 双栏指标看板**。
- **分析 → 数据大屏** 中存在 **官方示例 · 指挥台三栏大屏** 或 **官方示例 · 销售地理大屏**。
- **报表 → 报表中心** 可正常打开。
- （可选）在 **报表中心** 对 **预制分析** 点一次 **运行**，确认表格有数据行；失败则改口说明“只展示入口，不现场运行”。

若任一页面持续加载或报错，不要在会上临时修库。按下文“故障快速切换”改用相邻场景。

### 4. 准备浏览器

- 关闭下载栏、开发者工具和无关标签页。
- 浏览器缩放恢复到 100%。
- 预先打开两个标签页：
  - 标签 1：`/admin/dashboards`
  - 标签 2：`/admin/data-screens`
- 关闭系统通知和即时通信弹窗。
- 记住：管理员在列表中点击名称可能进入编辑页；演示查看态时应点击行尾的 **查看**（眼睛图标）。

### 5. 准备兜底材料

- 保留本手册。
- 准备一张已确认的大屏截图或录屏作为网络故障兜底。
- 记录当次演示前健康检查时间；出现问题时便于运维按时间查日志。

## 03:00–06:00｜统一管理数据连接

### 讲解口径

“连接管理负责回答‘数据在哪里’。VitalSpan 通过连接器统一登记关系型、OLAP、时序、文档、搜索、文件和 API 等数据源。图表可以直接查询源库，也可以先同步到托管分析库后再使用。”

### 现场操作

1. 在左侧导航展开 **数据准备**。
2. 展开 **数据连接**，点击 **连接管理**。
3. 在“数据源”列表找到带 **官方示例数据** 标记的连接。
4. 只展示连接类型、地址摘要和状态，不点击编辑或删除。

### 成功信号

- 页头显示 **数据源**。
- 页面说明为“配置与管理数据库、文件及 API 连接，供图表与看板直接查询使用。”
- 官方示例连接可见，连接卡片或表格正常加载。

### 可回答的问题

**为什么不直接查所有业务库？**  
外部源 Dataset 实时查询经 pandas 清洗；同步入托管分析库适合历史分析与减轻业务库压力。

**能接不同数据库吗？**  
连接器按类型扩展。连接/查询支持范围较广；同步是否作为生产主路径，还要看具体连接器的验收状态。

### 过渡语

“连接解决了‘从哪里读’，同步任务继续解决‘读哪张表、怎样洗、写到哪里’。”

## 06:00–10:00｜查看同步任务与 ETL

### 讲解口径

“VitalSpan 的同步任务按表管理。一个任务把一张源表同步到一张目标表，可选择全量覆盖或增量 upsert，并在写入前执行轻量 ETL。ETL 就是抽取、转换、加载中的转换环节，例如列重命名、类型转换、空值填充和行过滤。”

### 现场操作

1. 在 **数据连接** 下点击 **同步任务**。
2. 查看页头下方的任务指标和任务列表。
3. 选择一条已有任务，点击行尾 **查看运行历史**。
4. 指出历史中的状态、同步行数和执行时间，然后返回任务列表。
5. 在同一任务行找到 **配置清洗规则**，只进入查看；不修改、不保存。
6. 返回任务列表，指出 **手动运行同步** 图标，但不要点击。

### 成功信号

- 页头显示 **同步任务**。
- 页面说明为“管理源库到托管分析库的全量同步任务，配置定时计划与清洗规则。”
- 运行历史能显示既有记录；清洗规则页面能正常打开。

### 必须说清的边界

- 同步任务不是清洗整个数据库，而是**一表一任务**。
- 全量同步可能清空并覆盖目标表；因此本次演示不现场运行。
- 同步后的业务数据进入托管分析库；平台元库只保存任务配置和运行历史。

### 过渡语

“数据落到分析库后，还需要用业务可理解的方式组织字段，这就是 Dataset 的作用。”

### 可回答的问题

**仪表板和大屏有什么区别？**  
仪表板偏日常分析和交互，通常按网页布局使用；大屏按固定分辨率设计，强调投放、视觉和像素级排版。两者复用同一套图表与数据能力。

**为什么既有模板又有看板？**  
模板是可复用蓝图，看板是实际使用的实例。模板不承载具体用户日常修改。

## 28:00–30:00｜总结与问答

### 60 秒总结口径

“VitalSpan 的主链路是：多源数据先进入统一连接管理，需要清洗时按表同步到托管分析库，再由 Dataset 组织业务字段，最终在仪表板、大屏和报表中消费。平台坚持自研可控、权限可配置和政企内网友好，并为后续查询治理、总线发布和 AI 辅助配置保留扩展接口。”

### 用一条链回顾

```text
数据连接
  → 可选：同步任务 + ETL
  → 托管分析库
  → Dataset
  → 图表 / 仪表板 / 数据大屏
  → 定时报告 / 固定版式报表
```

### 常见问答

**VitalSpan 与 DataEase、Superset 的关系是什么？**  
只做能力和交互对标。VitalSpan 不嵌入、不 fork，也不依赖它们的生产运行时。

**为什么分析库使用 PostgreSQL，不直接用 Doris？**  
当前交付以单机/compose 和工程简化为主，PostgreSQL 能满足现阶段规模。后续若进入大规模并发 OLAP 场景，可按架构决策引入专用分析引擎。

**同步任务会处理整个数据库吗？**  
不会。一项任务处理一张源表和一张目标表，清洗规则也只作用于该任务的数据。

**能接不同类型的数据源吗？**  
能。平台通过连接器支持 SQL 和 Native 两类查询路径；具体类型能否用于生产同步，应以该连接器的验收状态为准。

**以后可以接 AI 自动生成图表吗？**  
架构上可让 AI 生成图表配置、样式或只读 SQL，再交给现有校验和查询链执行。但 AI/SQL 智能问数当前尚未立项，不能作为已交付能力演示。

**权限怎么控制？**  
平台支持角色、数据源可见性和行级权限。管理员负责配置；本次演示使用管理员账号，不展开多角色写操作。

## 可选加场（内部评审 · 时间充裕时）

主路径仍为「数据准备 → 消费 → 报表」。若听众更关心**先看效果**，可在登录后先演示 **官方示例 · 双栏指标看板** 与 **销售地理大屏**，再回补数据连接与同步环节。

### RBAC 速览（约 3 分钟）

1. 点击右上角用户菜单 → **后台管理**。
2. 展示 **首租户配置向导**（组织 → 岗位角色 → 用户 → 资源授权）。
3. 可深链 **角色管理** 或 **审计日志**，只查看、不修改。
4. （可选）退出后用 `analyst` 或 `viewer` 登录，说明侧栏无 **数据准备** 分组。

### 明确不进主路径

- **治理**（接口目录、工单、发布流水线）及 **查询设计器**：侧栏默认隐藏，页顶有「未对接真实总线」提示。
- **定时报告** 手动执行、PDF 邮件试发、同步 **立即运行**、Embed SDK Demo。

## 故障快速切换

| 现场现象 | 主讲人立即操作 | 讲解口径 |
|----------|----------------|----------|
| 无法打开 `:8088` | 切到准备好的截图或录屏 | “当前是内网演示环境，先用已验收画面继续产品讲解。” |
| 登录后提示操作失败 | `Ctrl+F5` 强刷一次；仍失败则停止重试 | “前端版本或 API 同源配置需要运维确认，不在现场修改环境。” |
| 数据连接页面无数据 | 跳到可视化模板 | “连接管理负责多源登记，下面直接看已绑定演示数据的分析结果。” |
| 同步任务无历史 | 只讲数据流图，跳到 Dataset | “本次采用只读基线，不现场触发可能覆盖目标表的同步。” |
| Dataset 页面加载失败 | 跳到官方示例看板 | “语义层异常不影响我们说明最终消费形态，会后按 Trace ID 排查。” |
| 看板图表无数据 | 切换到 **可视化模板 → 预览** | “模板预览用于验证布局和视觉；真实出数依赖示例数据源状态。” |
| 3D 大屏卡顿或黑屏 | 改看 **指挥台三栏大屏** 或 2D 看板 | “3D 使用 WebGL，运行环境不足时产品会走质量降级路径。” |
| 地图边框装饰异常 | 切换另一大屏，不现场编辑 | “该问题与非安全上下文兼容有关，已登记版本核对项。” |
| 报表中心探测失败 | 只展示模板/调度列表，不执行 | “报表生成与邮件都有环境门禁，探测失败时不会假成功。” |
| 页面突然进入无关 `sc-datav` Demo | 关闭该标签，重新输入 VitalSpan URL | “`sc-datav` 仅是 3D 视觉参考项目，不是 VitalSpan 业务页面。” |

处理原则：

1. 同一动作失败两次后停止重复点击。
2. 记录页面、时间和用户可见提示。
3. 不在投屏过程中修改 `.env`、重启服务、恢复数据库或运行部署脚本。
4. 不为了继续演示而关闭权限、绕过鉴权或伪造成功结果。

## 演示后复位

本手册主路径不产生写操作，正常情况下无需数据库复位。

1. 退出 VitalSpan 或关闭演示浏览器窗口。
2. 确认没有误点 **运行**、**保存**、**删除**、**创建定时报告**或邮件试发。
3. 若误触写操作，记录账号、时间、页面和对象名称，联系环境管理员处理；不要继续删除对象“抵消”操作。
4. 若怀疑服务异常，环境管理员可检查：
   - `vitalspan-backend`
   - `nginx`
   - staging 健康检查
   - 对应时间段的 `traceId`
5. 若必须恢复已知数据基线，由环境管理员先备份，再按部署日志执行恢复。不要在演示手册中复制数据库、SSH 或国密密钥。
